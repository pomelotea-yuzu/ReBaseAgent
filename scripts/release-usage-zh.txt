ReBaseAgent 使用说明（v{{VERSION}}）
=====================

【这是什么】

ReBaseAgent 是一个 Agent 的时间旅行调试器：录下 AI Agent 的每一次运行，
回看每一步模型当时看到的内容，并能改掉跑歪的那一步、只重跑必要的那段。
所有数据保存在你自己的电脑上。

【压缩包里有什么】

- ReBaseAgent-{{VERSION}}-win-x64-portable.exe —— 桌面主程序，双击即用
- mcp\ —— MCP 只读诊断服务（供 AI 工具接入查询运行记录，详见下方专节）
- SHA256SUMS.txt —— 全部文件的 SHA-256 校验值
- 使用说明.txt —— 本文件

【运行要求】

- Windows 10 / 11（64 位）
- 无需安装，免管理员权限

【怎么开始】

1. 把压缩包解压到一个固定的文件夹（例如 D:\ReBaseAgent\）。
   建议用 7-Zip 或 WinRAR 解压。
2. 双击文件夹里的 ReBaseAgent-*.exe 即可启动。
3. 首次运行可能弹出「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」。
   （本程序未购买代码签名证书，属个人开源项目，此提示为系统对未签名
   程序的常规提醒；可先用压缩包内 SHA256SUMS.txt 核对文件完整性。）
4. 首次启动会自动在 exe 同级生成 data\ 目录。注意：不会自动创建示例运行——
   列表为空属正常，先在程序里新建一次运行（需配置模型 API）产生第一条记录。

【数据保存在哪里】

- 所有运行记录、设置、配置都存在 exe 同级的 data\ 文件夹里。
- 不写注册表、不写 C:\Users\你\AppData，删掉 data\ 文件夹即彻底清除数据。
- 想备份：直接复制整个文件夹（含 data\）。
- 注意：把 exe 移动到别的目录 = 换了一个新的数据目录，
  原来的数据还在旧目录里。

【怎么升级】

- 下载新版 zip，解压后用新 exe 替换旧 exe（保留同级 data\ 文件夹），
  历史运行数据全部保留。
- 也可以解压到新文件夹从零开始，互不影响。

【模型接入】

- API Key 只保存在本地，请求由你的电脑直连服务商，
  本程序不经过任何第三方服务器。
- 也可以用内置的「本地录制代理」：让 Agent 应用的 base_url 指向
  本地代理端口，即可边使用边录制，无需改代码。

【项目验证】

在文件页选择一个检查点，展开「项目验证」，可在受限 Docker 容器里
对当时的源码跑固定类型检查或可信测试，并保存可回查的记录与日志。

- 环境要求：Windows x64 + Docker Desktop（Linux containers）。
  应用不安装引擎，也不接受 WSL / 远程 Docker / Podman。
- 当前只支持 node-ts-v1 模板：受测源码限 src\**\*.ts，测试来自受信镜像，
  命令只有 typecheck / test 两种；不接受自定义命令、依赖或镜像。
- 首次准备环境需要联网拉取固定镜像与工具链（带完整性校验）；
  正式测试阶段容器断网。
- 验证不会自动发起模型修复；修复应来自你已记录的运行分支。
- 真实项目接入与更多语言模板仍待后续版本，当前请按模板范围使用。

【MCP 只读诊断（AI 工具接入）】

mcp\ 文件夹是 ReBaseAgent 的 MCP 服务：让你正在用的 AI 工具
（支持 MCP 的客户端，如 WorkBuddy、Trae、Cursor 等）直接查询
ReBaseAgent 的运行记录——查运行清单、步骤正文、两侧比较、
检查点文件，以及项目验证的命令、日志、产物与条件比较。
共 **13 个只读工具**，**只读**：不写盘、不执行工具、不调用模型。

- 运行要求：Node.js ≥ 20（部分客户端自带 Node，如 WorkBuddy）。
- 前提：先启动一次桌面主程序生成 data\ 数据目录，并至少完成一次运行
  （MCP 查询的是已有运行记录；目录为空时查询返回空列表，不是配置错误）。
- 配置方法（在客户端的 MCP 设置里添加，类型 stdio）：
    命令：node   （或你机器上 node.exe 的完整路径）
    参数：<解压目录>\mcp\dist\cli.js --data-dir <解压目录>\data
  其中 --data-dir 指向你的数据目录（便携版默认是 exe 旁的 data\）。
- 完整接入说明（配置示例、能力边界、费用与已知限制）：
  项目仓库 docs/guide/mcp-readonly-diagnostics.md。

注意：MCP 服务对数据目录零写入；查询不会修改你的任何运行记录。

【常见问题】

Q: 双击提示「Windows 已保护你的电脑」？
A: 点「更多信息」→「仍要运行」。介意的话先用 SHA256SUMS.txt 核对
   文件哈希（命令：certutil -hashfile 文件名 SHA256），与 Release 页
   公布的值一致即可放心。

Q: 杀毒软件报毒 / 提示未签名程序？
A: 未签名程序的常规误报。可将本程序所在目录加入杀毒软件的信任区；
   如仍有顾虑，项目全部源码开源，欢迎自行审查或从源码构建，
   我们也在评估代码签名方案，希望后续版本能带来更顺滑的安装体验。

Q: 关闭窗口时弹出确认框？
A: 有未保存的编辑草稿时的正常保护，确认后才会关闭。

Q: 数据会传到网上吗？
A: 运行记录永远只存本地；只有向模型服务商发起对话时才会联网，
   且按你的配置直连。MCP 服务同样零出网。
