# 编辑与差异工作区页头布局复查

2026-10-10，基于 main `1965391`。本次是已归档 UI change 后的布局修正，与 R2.1 导出 change 无关。

## 调整

- 运行页头横向安排任务和运行身份；模型实验、重新打开目录、专注模式与页签共用一行。
- messages 页只保留一个标题；标题与目标在左，返回和详细说明在右。原值和草稿上沿对齐。
- 工具调用的耗时与草稿状态保持可见；入参与原始结果、重跑说明可展开。运行草稿列表默认收起，入口保留数量。
- 文件检查点保留选择和简短只读摘要；来源、快照和 profile 进入右侧的展开说明。当前文件与工具栏横向排布，复制操作集中到菜单。
- 输出 diff 的左右短 ID 和完整 ID 复制入口放在页头。必要摘要与详细说明分开，正文使用剩余高度。
- 提交核对卡保留关键执行摘要、资格原因和确认动作，删除重复摘要；详细边界放在右侧。

## 实机发现并修复的草稿覆盖

通过 CDP `Input.insertText` 写入中文、日文和非法 JSON，随后收起、恢复原值，复现了草稿被原值覆盖：修订从 5 推进到 6，编辑文本退回基线。原值/草稿在 React 子节点中没有稳定 key，收起原值时原值宿主被复用为草稿宿主。

`DraftCompareGrid` 为原值、草稿和调整手柄设置独立 key。修复后，并排和上下两种布局中，收起/恢复原值、展开/收起说明、录制页往返都保持文本与修订；测试结束后恢复输入前的文本。未提交模型请求。
