## 观察与建议

### 1. 文件页重复说明明显占用高度

07 的同一段隔离说明在运行页头与文件区各显示一次，此外还有独立来源说明、只读边界、snapshot/profile 元信息。隔离运行不能做模型实验的解释也独占一行。

本次从比较返回后另有一条“返回比较”提示带，故该截图的总占用包含这一导航上下文；不能把 y=509 当成所有文件页的固定尺寸。在这条实际路径里，diff 从 y≈509 开始，编辑器内部分配高度约 427px，但首屏可见最多约 204px（713−509），约占视口高度 29%。

建议统一隔离说明的展示位置，常驻短句“文件隔离 · 源目录不受影响”，保留“来源与隔离说明”展开入口；profile、world_id、snapshot/hash 的详细解释进入详情区。当前检查点、两侧身份与异常提示保持可见。将不适用功能及原因放到动作菜单或可展开能力说明，避免持续占一行。diff 使用剩余内容区高度，避免固定 vh 的编辑器外再套需要滚动的内容区。

### 2. messages 编辑器高度固定，重复标题与说明增加滚动

02/08 中工作区标题与编辑器标题都是“编辑 messages 重发”。外层说明、编辑器右侧说明、编辑器下方说明、确认区又多次讲述单请求和凭据边界。两个编辑器各约 198px 高，原值从 y≈189 开始，草稿从 y≈414 开始；确认按钮从 y≈953 开始，超出首屏。

源码 MessagesForkEditor 使用 `height="200px"` 与 `xl:grid-cols-2`。当前 1210px 视口未到 xl，因此上下排。09 证明收起列表只把编辑器宽度从约 865px 增至 1129px，高度仍约 198px，也仍上下排。是否并排应综合实际容器宽度与每侧最小阅读宽度，不能只追随窗口断点。

建议编辑区占主体，提供明确的“专注编辑 / 退出专注”操作；原值可收起，并可按实际宽度切换并排、上下或单侧编辑。编辑器随可用空间伸缩，并允许调整原值/草稿比例。保留当前目标、请求会发往哪里、凭据状态与关键执行边界，用短摘要呈现；长说明按需展开。核对与提交就近安排在可见操作栏，继续绑定当前草稿和配置，不因折叠、往返而恢复旧授权。

### 3. 折叠入口的可发现性不一致

运行列表页头的“‹”按钮实测约 16 × 16 CSS px，颜色浅；另一个入口在全局栏，是约 28 × 28 的无文字图标。LongText 的折叠入口是 11px 灰色 summary；它有“点击展开完整内容”的文案，但视觉上接近正文注释。文件目录有文字按钮，比列表箭头明确，位置却在检查点区右端，远离目录本身。

建议统一成明确的标题栏控制：方向箭头 + “收起列表 / 展开列表”“收起说明 / 展开说明”，整个标题行具备合理点击区域与焦点样式，状态和动作一致。目录开关尽量就近放在目录标题；收起后保留易发现的恢复入口。不得把页面面板折叠与 Monaco 的代码折叠混成一个操作。

### 4. 输出比较的修改证据可以收起

04 中输出 diff 自身两侧约 450px 宽、443px 高，空间比文件页充足；底部修改证据持续展开。建议保留“修改证据 · 字段/修改数”的摘要与可见开关，正文按需展开，让长输出 diff 获得更多高度。保持左/右对应运行可辨认；不要把身份全隐藏在 tooltip 中。

### 5. 产品文案包含较多实现术语

10 的确认区和结果空态直接使用 main 登记、config_hash、被动录制不补结果等术语。“最近捕获”还以字面 `**` 显示。信息对维护者有用，但常驻主流程会增加理解成本。

建议主界面表达用户会遇到的结果，例如“仅重发本次模型请求，不执行外部工具”“使用本会话最近收到的凭据”“尚未提交重发”。实现细节放到可展开的技术详情。折叠一般说明时保留异常、执行范围和必要确认，不能只把所有文字统一隐藏。

## 对原反馈的补充核对

- 09 的已读取请求快照为 `[{"role":"user","content":"????????? LLM ???"}]`，问号已存在于源数据。对这条视频样本，可排除 Monaco 把正常中文显示成问号；需查录制前的数据构造/脚本编码，不能推断全部 Unicode 路径都正确。
- 本次正常浏览未复现 messages 编辑器容器塌缩。04/07 的 DOM 中另有一个 0×0 Monaco 元素，同时两侧编辑器正常显示；单凭选择器命中某个零尺寸节点不能确认可见编辑器塌缩。后续须记录可见宿主、祖先链、活动 editor 与所属目标。
- 这只是单个真实视口的可用性检查，尚未完成宽/窄窗口、缩放矩阵、键盘和长草稿输入回归。

## 建议立项

建议另立 `improve-workspace-reading-and-editing`，与代理状态同步/失败诊断的可靠性 change 分开管理。范围为统一折叠入口、说明去重与分层、编辑区自适应、专注编辑、确认/提交就近布局；不扩展执行能力，不改变历史事实、单请求重发边界与授权纪律。

建议验收包含：真实窗口下折叠入口可通过键盘发现并操作；收起后恢复入口仍可见；同一说明不在同屏重复；普通文件页内容区至少获得约半屏高度（低高度异常提示另行记录）；编辑区不会固定为小块而下方保留大量空白；核对与提交可在同一操作区完成；折叠、专注切换和页面往返保持草稿、选中目标和阅读位置，旧确认继续失效。以本次截图作为基线补充宽窄窗口和缩放回归。
