## 证据口径

- **官方文档**：记录访问日期、页面与适用范围，只支持页面明确描述的能力。
- **实现证据**：链接源码与行为规范，说明适用入口和限制。
- **测试源码**：说明已有测试覆盖的断言，不代表本次重新运行成功。
- **执行证据**：必须带命令、环境、提交或输入哈希、结果与失败记录。
- **待验证假设**：给出验证方法和可否定条件，不预填性能、效果或使用数据。
