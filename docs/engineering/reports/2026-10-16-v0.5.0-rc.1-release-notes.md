# ReBaseAgent v0.5.0-rc.1 发行候选 — 结果导出、界面重组与对象身份打磨

Agent 的时间旅行调试器。不止回放 Agent 做了什么，而是让你改变它做了什么。

Agent 跑歪时，bug 往往不在你的 loop 代码里，而在某一步的上下文里。云端平台能看但数据出境，本地抓包工具只读不可改。ReBaseAgent 让你回到跑歪的那一步，改掉脏掉的上下文，只重跑必要的那段 —— 轨迹保存在本地，真实模型请求按你的配置发往服务商。

## 相对 v0.4.0-rc.2 新增（一）：结果导出（R2.1）

把一次调试结论导出成**自包含、可带走**的材料 —— 调试成功的结果不再锁在本地数据目录里。

- **文件页导出入口**：选中检查点后一键导出；确认卡先核对三件事 —— 目标是空目录、会写入哪些内容、哪些内容不保留，且**不接受手输物理路径**（只走系统目录对话框），防误写。
- **导出物自包含**：文件快照 + 补丁状态清单（`source` / `patch.status`），逐字节复核附件哈希；失败时逆序清理半成品，不留脏目录。
- **四态反馈如实**：成功 / 取消 / 失败（来源重验不过、目标非空等各给真实原因）各有明确文案，切换检查点时旧反馈收起不串显。
- **只读保证**：导出全程不修改已有数据——纯阅读阶段 trace/附件/源目录指纹逐字节不变（实机验证）；隔离续跑的 fork 不从历史阅读状态继承执行授权。

## 相对 v0.4.0-rc.2 新增（二）：界面重组与对象身份（社区发行打磨）

**① 对象身份归位** —— 单运行、比较、新建、实验各有明确对象头；**完整运行 ID 一键可查可复制**（页头与实验对象头均支持，键盘可达）；比较页两侧身份各归其列、交换左右同步翻转，全局栏不再冒充任何一侧身份。

**② 视图术语与导航** —— 「运行记录 / 分支关系」双视图切换语义统一；切换不重载（全程零新增扫描，实机指纹验证）；运行列表**任务优先**排序、次级指标按需展开，同名长任务靠唯一短 ID 仍可辨认。

**③ 返回入口说真话** —— 各编辑 / 实验工作区的返回入口显式写明目的地（如「返回运行记录 · 调用步骤」）；来源失效时**不冒充可恢复**——就地给真实原因与退路，失效来源仍保护你的输入草稿。

**④ 会话活动统一入口** —— 底部「会话活动」条统一草稿 / 操作 / 结果三组事实：修改计数（含录制未应用修改）、主动操作登记、结果未读；跨页按操作身份精确定位结果或草稿，迟到响应不抢当前页面；面板关闭后未读仍可感知。

**⑤ 草稿状态诚实分组** —— 只打开没输入的编辑会话不冒充修改（clean 单独分组可找回）；改回基线恢复 clean；清空原非空输入**仍算修改**（清空保护）；放弃需确认模态，背景不可点。

**⑥ 表单与确认分层** —— 创建 / 实验表单空态给初始引导，点提交才就地核对（尝试核对就近报错，零 IPC）；实验表单阻塞原因成列、臂级错误就近标记；上游真实异常即时呈现，不等字段交互；执行确认摘要统一一套。

**⑦ 实机逼出并修复一个真实缺陷** —— 创建工作区整树白屏（状态引用不稳定导致 React 卸载整树），实机验收暴露后已修复并加回归钉。

**⑧ 坏数据显式可辨** —— 附件落盘字节与哈希不符时，文件页标「附件损坏」、汇总行报「N 个附件不可用」、导出禁用并说明；坏内容绝不冒充文件内容展示。

## 这版能做什么

- **录制 — trace 格式 v1 / v2**：JSONL 事实源，一 run 一文件，append-only；v2 在 `agent.step` 上带文件检查点字段，v1 照旧可读。
- **执行 — 纯 TypeScript 的 Agent 执行引擎**：OpenAI 兼容协议直连（DeepSeek / GLM / Qwen / Kimi 开箱即用），零厂商 SDK。
- **零摩擦录制 — 本地 LLM 录制代理**：独立录制工作区配置监听端口与 upstream，应用里把 `base_url` 指向本地代理即可录制；key 仅暂存内存、不落盘、不回传渲染层；上游写失败如实落 span 并保留草稿。
- **查看 — 三栏调试台**：导航 / 目录 / 详情三栏可调，支持专注模式；概览页看结果与消耗；独立文件页；span 时间线逐步回看每一步模型当时看到的完整上下文；状态徽标全界面一个判据。
- **文件阅读与导出（本版新增导出）**：检查点快照选择与导航、按真实变化筛选、路径查找、按宽度自适应的并排/inline diff、完整原文 + 查找/换行/复制、会话内恢复阅读位置、两侧状态诚实标注；**选中检查点可整目录导出带走**。
- **预算地图**：token 花在哪了，按消息 / 工具分布可视化。
- **时间旅行（四种改法，互不冲突）**：
  - (a) **改某步 `tool_result` 从该步重跑**：前缀全部本地命中，只有分支点之后才真正调 API；
  - (b) **隔离文件续跑**：带写工具的 run 在隔离副本世界里真重跑，源目录与父 run 逐字节不变；
  - (c) **prompt fork**：编辑 system_prompt 或首条 user_message，从头重跑一条独立新轨迹；
  - (d) **代理 messages 重发**：代理录下的 run 可编辑 messages 经代理重发，单请求级最小分叉。
- **模型 A/B 实验**：同上下文多臂并排（最多 4 臂），先校验并预览计划（费用确认）后真实调用；结果按批次分组、跨页存活。
- **多分支对照**：宽幅指标表 + 详细比较页 + 分支树，最多 4 条分支并排；比较对象身份清晰、切换不重载（本版强化）。
- **缓存记账**：前缀缓存命中/未命中单独记账；缺数据显示「未知」，不伪装成零命中。
- **调试草稿保护**：会话内按编辑身份保存、退出确认、活动条跨页定位（本版强化）。
- **操作追踪**：主动操作登记、幂等键、终态信封与结果 run ID、结果待看计数（本版接入统一活动入口）。
- **部分运行读取**：父链缺失时结构化降级，缺失项不补零、不推算，恢复后全量重验。

> 类比传统调试器：结果导出是「把复现材料打包给同事」，上下文预算地图是 Profiler，改 tool_result 重跑是「改一行代码重跑」，隔离文件续跑是「带副作用的操作也能安全回滚重跑」，会话活动条是「调用历史面板」，对象头完整 ID 是「可引用的断点地址」。

## 已知限制（诚实声明）

- **本版自动化门禁与离线冒烟全绿（desktop 203 文件 / 3180 用例 Errors=0；打包后离线冒烟 14 判据全过），§9.1 人工实机验收未执行**；需要时按 `2026-10-02-v0.4.0-rc.1-manual-acceptance-checklist.md` 清单口径补验。
- **执行中的 run 不出现在左侧列表**，完成后才出现——这是列表刷新时机的现行设计。
- **UI 未显示版本号**：窗口标题固定为 ReBaseAgent；核验版本请比对 zip 内 `SHA256SUMS.txt` 的 exe SHA-256。
- 文件视图只读，且只列出**本 run 自己写过的**文件；不提供跨 run 文件 diff。
- 目前只构建了 **Windows x64**，macOS / Linux 尚未出包。
- 接入仍需手工：要么在代码里接 SDK，要么把应用 `base_url` 指向本地录制代理。一键埋点与 Anthropic 协议尚未支持（代理只绑 `127.0.0.1`、仅 OpenAI-compatible `/v1/chat/completions`）。
- 时间旅行默认 **world-free 重放**；隔离文件续跑是例外。prompt fork、代理重发、模型 A/B 与隔离续跑都是**真实重跑**，会按 provider 计费。
- 模型 A/B 是**实验对比**，不做「哪个模型更好」的排名；不产出臂间差值或胜出臂结论。
- 批量写盘占用尚无长期管理：隔离快照与共享附件会随 run 累积，重度使用请留意 `data/` 体积。
- 渲染层无 error boundary；部分遗留项归后续 change。
- 不做：中间消息任意编辑、span 级 diff、模型 A/B 排名、NSIS 安装包、arm64 构建。
