## 构建坑（本轮）

- 火绒拦截 electron-builder 缓存工具的老问题仍在：继续用
  `ELECTRON_BUILDER_7ZIP_PATH=C:\Program Files\7-Zip\7z.exe`、
  `ELECTRON_BUILDER_NSIS_DIR=D:\ReBaseAgent\.rebaseagent\nsis-clean` 与离线
  `-c.electronDist=D:/ReBaseAgent/.rebaseagent/electron-dist`。
- **zip 内嵌 `使用说明.txt`**：打包后修改 `scripts/release-usage-zh.txt` 必须重打 zip
  （exe 不受影响）。本轮因把“项目验证（本版新增）”改成“项目验证”，zip 重打了一次；
  最终校验值以本记录为准。
- **根 run ID 碰撞由 CI 暴露**：`runLoop` 只用时间戳；同一毫秒创建 create 与父本会得到
  相同 ID，后写 `rename` 覆盖前者。`5ef3ec7` 加随机后缀并有固定时钟回归；新增 run/fork/
  experiment ID 一律要带熵。

## 回退方法

`0.7.0-rc.1` 的 exe/zip 在 `release/stable/` 原样保留（哈希见上）。但 rc.1 含上述 ID 碰撞
风险，仅在 rc.2 出现新问题时临时回退；正常应优先使用 rc.2。
