## 相对 v0.7.0-rc.1 修复

### 1. 根 run ID 同毫秒碰撞（会导致历史记录被覆盖）

- **现象**：根 run 的 ID 原先只由毫秒时间戳生成（`run_<ts>`）。同一毫秒内创建两个 run（例如快速连续新建，或测试中先 create 再创建父本）会得到相同 ID；后落盘者按 `${id}.jsonl` 改名时覆盖前一个 trace，等同于静默丢失一条运行记录。
- **修复**：根 run ID 改为 `run_<ts>_<random6>`，与 replay 的 `newRunId` 同形；新增“固定时钟 + 不同随机数”的唯一性回归。
- **兼容**：旧 trace 的 ID 不受影响，照常可读、可分叉；无需迁移。

### 2. CI 与平台判定修正（不改变 Windows 用户可见行为）

- Docker CLI 候选只在 Windows 返回受信绝对路径；其他平台明确返回空表，不再伪造 Windows 路径。
- Windows 候选路径改用 `path.win32` 构造，避免在非 Windows 宿主上被拼成正斜杠。
- 权限注入、限额击杀与 R3 端点用例改为不依赖 root/固定 sleep 的确定性写法。

## 这版能做什么（与 rc.1 相同）

- **录制 — trace 格式 v1 / v2 / v3**：JSONL 事实源，一 run 一文件，append-only；旧版本照旧可读。
- **执行 — 纯 TypeScript 的 Agent 执行引擎**：OpenAI 兼容协议直连，零厂商 SDK。
- **零摩擦录制 — 本地 LLM 录制代理**：key 仅暂存内存、不落盘、不回传渲染层。
- **查看 — 三栏调试台**：概览、步骤、文件页与 span 时间线；状态徽标全界面一个判据。
- **时间旅行（四种改法）**：改某步 `tool_result` 从该步重跑；隔离文件续跑；prompt fork；代理 messages 重发。
- **隔离 prompt 实验（R2.2）**：根初始快照上的单变量实验、v3 记录、跨运行比较与单侧导出。
- **隔离项目验证（R3）**：Docker Desktop 受限容器、`node-ts-v1` 固定模板、准备/执行分开授权、双验证比较与精确输入导出。
- **MCP 只读诊断（十三工具）**：运行、检查点与 R3 验证记录查询；只读、零写入、64 KiB 预算与认证游标。
- **文件阅读与导出、模型 A/B、多分支对照、缓存记账、预算地图、草稿保护、操作追踪、部分运行读取**：沿用 0.6/0.7 rc.1 已交付口径。

> 完整功能说明与限制见 [v0.7.0-rc.1 发行文案](2026-10-26-v0.7.0-rc.1-release-notes.md)；本包只修复上述问题。

## 已知限制（诚实声明）

- **本版自动化门禁与离线冒烟全绿（desktop 225 文件 / 3474 用例；zip 组装三段自验、解压后十三工具自跑、打包后离线冒烟 12 判据全过），§9.1 人工实机验收未执行**；R3 面板的视觉/键盘/窄窗/200%/原生目录对话框实机取证也尚未完成。
- **rc.1 的 ID 碰撞问题已在 rc.2 修复**；请优先使用 rc.2。rc.1 仅在确认 rc.2 有新问题时临时回退。
- **R3 只声明模板范围**：仅 Windows x64 + Docker Desktop（Linux containers）+ `node-ts-v1`；真实项目接入（I 组 7.1/7.2）未排期；不支持 WSL / 远程 Docker / Podman。
- **R3 环境来源**：首次准备需联网拉取固定镜像与 npm 工具链；基础镜像与 Docker Hub 官方源的一致性核对、Alpine 基础包逐包许可汇总仍未完成。
- **R3 不自动发起模型修复**：修复必须来自已记录的运行分支。
- **MCP 需要 Node ≥ 20**；首次使用前先启动一次桌面主程序生成 `data/` 目录。
- **不透传 `structuredContent` 的客户端（含 WorkBuddy / Trae）看不到 MCP 续读游标**（指南 §8）。
- **MCP2 未用 0.7 发行包重跑外部客户端验收**；WorkBuddy 5.9.2 回查基于源码/开发数据根。
- **UI 未显示版本号**：核验版本请比对 zip 内 `SHA256SUMS.txt` 的 exe SHA-256。
- 文件视图只读；跨 run 文件比较由实验比较视图承载；仅构建 Windows x64。
- 隔离续跑、prompt fork、代理重发、模型 A/B 与隔离 prompt 实验都是真实重跑，会按 provider 计费；R3 验证与 MCP 查询本身零模型调用。
- 批量写盘占用尚无长期管理；本版 zip 约 100.7 MB（主因 `mcp/` 依赖闭包）。
- 渲染层无 error boundary；不做中间消息任意编辑、span 级 diff、模型排名、NSIS 安装包、arm64、内置 Agent 调用外部 MCP 工具、MCP 受控执行（归 MCP3）。
