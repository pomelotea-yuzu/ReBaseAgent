# ReBaseAgent v0.4.0-rc.2 发行候选 — 编辑器恢复契约、代理录制可靠性、工作区阅读体验

Agent 的时间旅行调试器。不止回放 Agent 做了什么，而是让你改变它做了什么。

Agent 跑歪时，bug 往往不在你的 loop 代码里，而在某一步的上下文里。云端平台能看但数据出境，本地抓包工具只读不可改。ReBaseAgent 让你回到跑歪的那一步，改掉脏掉的上下文，只重跑必要的那段 —— 轨迹保存在本地，真实模型请求按你的配置发往服务商。

## 相对 v0.4.0-rc.1 新增（一）：工作区阅读与编辑体验

**① 折叠与信息分层统一** —— 各工作区的折叠控制归一并记住状态，长内容默认收起、按需展开，减少一屏塞满的压迫感。

**② 专注模式** —— 临时覆盖收起导航 / 目录 / 辅助区，把整窗留给正文；再按一次或 Esc 即恢复原布局。

**③ 文件页与对照区的可用高度** —— 文件 diff 建立完整高度链，挤压下限（最小 200px）兜底不再塌陷；原值 / 草稿对照区按容器实测适配；Monaco diff 宿主尺寸恢复正常，编辑器视图状态（滚动位置 / 选区）按编辑身份保存并在返回时恢复。

**④ 执行入口统一确认块** —— 六个主动执行入口（重跑 / 续跑 / fork / 代理重发 / A/B / 导出等）共用一套确认块：摘要收起时可见、详细边界可展开，改参数不再要重新读一遍整套说明。

**⑤ 模态与文案打磨** —— 模态默认限高 85vh 内滚动、遮罩加深；主流程文案去掉实现术语，技术说明收进可展开的 Disclosure；失败 run 的列表徽标补占位说明；工作区头部布局重排。

**⑥ 小窗口与缩放适配** —— 1024px / 800px / zoom 2 三档实机核过：折叠、专注、草稿、确认提交、模态均可纯键盘完成。

## 相对 v0.4.0-rc.1 新增（二）：编辑器恢复契约

**加载失败可就地恢复** —— Monaco 编辑器加载失败时给出明确的失败态与「就地重试」，恢复后尺寸与视图状态回归原位；恢复判据按「可见性 + 尺寸 + 身份锚点」验收，最小化还原与面板往返两档实机验证通过。

> 诚实边界：触发塌缩的原始路径在本轮验收环境中未能复现，因此本版交付的是**恢复契约与可寻址判据**（失败态另有 18 个渲染用例承载），不是对某个已复现崩溃的修复。

## 相对 v0.4.0-rc.1 新增（三）：代理录制可靠性

**① 上游写失败如实落 span** —— 代理录制的 run 在上游写失败时失败信息落 span、详情页标注占位，跨包锁定诊断口径统一；不再虚报「新记录已保存」，主动侧失败时草稿原样保留。

**② 失败父本的重发路径收敛** —— 对失败父本做编辑重发时，成功路径与门禁拒绝（来源失效、参数不完整）都有明确出口，不会静默通过。

## 这版能做什么

- **录制 — trace 格式 v1 / v2**：JSONL 事实源，一 run 一文件，append-only；v2 在 `agent.step` 上带文件检查点字段，v1 照旧可读（两版本严格匹配，字段错配即拒）。
- **执行 — 纯 TypeScript 的 Agent 执行引擎**：OpenAI 兼容协议直连（DeepSeek / GLM / Qwen / Kimi 开箱即用），零厂商 SDK。
- **零摩擦录制 — 本地 LLM 录制代理**：独立录制工作区配置监听端口与 upstream，应用里把 `base_url` 指向本地代理即可录制；key 仅暂存内存、不落盘、不回传渲染层；上游写失败如实落 span 并保留草稿（本版新增）。
- **查看 — 三栏调试台**：导航 / 目录 / 详情三栏可调，支持专注模式（本版新增）；概览页看结果与消耗；独立文件页；span 时间线逐步回看每一步模型当时看到的完整上下文；状态徽标全界面一个判据。
- **文件阅读**：检查点快照选择与导航、按真实变化筛选、路径查找、按宽度自适应的并排/inline diff、完整原文 + 查找/换行/复制、会话内恢复阅读位置、两侧状态诚实标注 —— 全程只读。
- **编辑器（本版强化）**：Monaco diff 宿主尺寸恢复、视图状态按身份保存恢复、加载失败就地重试。
- **预算地图**：token 花在哪了，按消息 / 工具分布可视化。
- **时间旅行（四种改法，互不冲突）**：
  - (a) **改某步 `tool_result` 从该步重跑**：前缀全部本地命中，只有分支点之后才真正调 API；
  - (b) **隔离文件续跑**：带写工具的 run 在隔离副本世界里真重跑，源目录与父 run 逐字节不变；
  - (c) **prompt fork**：编辑 system_prompt 或首条 user_message，从头重跑一条独立新轨迹；
  - (d) **代理 messages 重发**：代理录下的 run 可编辑 messages 经代理重发，单请求级最小分叉。
- **模型 A/B 实验**：同上下文多臂并排（最多 4 臂），独立实验工作区，先校验并预览计划（费用确认）后真实调用；结果按批次分组、跨页存活；分支树按「换 model/params」归组。
- **缓存记账**：前缀缓存命中/未命中单独记账；缺数据显示「未知」，不伪装成零命中；父链不完整时指标不补零、不推算。
- **LLM 失败详情**：失败标记、span 级错误详情（含 HTTP 状态码）、key 脱敏落盘（实机验证：`****9999`），重启后仍可查。
- **多分支对照**：宽幅指标表 + 详细比较页 + 分支树，最多 4 条分支并排；修改证据记录每次分叉；比较页文本差异面板有挤压下限（本版修复）。
- **调试草稿保护**：会话内按编辑身份保存、退出确认、草稿可定位。
- **操作追踪**：主动操作登记、幂等键、终态信封与结果 run ID、结果待看计数。
- **部分运行读取**：父链缺失时结构化降级，缺失项不补零、不推算，恢复后全量重验。

> 类比传统调试器：上下文预算地图是 Profiler，改 tool_result 重跑是「改一行代码重跑」，
> 隔离文件续跑是「带副作用的操作也能安全回滚重跑」，分支树 + 宽幅指标表是「并排看两个分支的代价与结局」，
> 操作追踪是「调用历史面板」，草稿保护是「未保存更改警告」，编辑器恢复契约是「崩溃后恢复现场」。

## 已知限制（诚实声明）

- **本版自动化验收与离线冒烟全绿，人工实机验收未执行**（补打包性质）；如需按 rc.1 同清单人工验收，清单见 `2026-10-02-v0.4.0-rc.1-manual-acceptance-checklist.md`。
- **代理「核对中 / 恢复中」中间态在实机上采不到**（毫秒级窗口），相关行为由自动化用例承载，实机只验终态。
- **编辑器「塌缩」原始路径未复现**：本版交付的是恢复契约与判据（见上），不是对已复现崩溃的修复。
- **执行中的 run 不出现在左侧列表**，完成后才出现——这是列表刷新时机的现行设计。
- **UI 未显示版本号**：窗口标题固定为 ReBaseAgent；核验版本请比对 exe 的 SHA-256。
- 文件视图仍然只读，且只列出**本 run 自己写过的**文件；不提供导出、跨 run 文件 diff（结果导出 R2.1 开发中）。
- 目前只构建了 **Windows x64**，macOS / Linux 尚未出包。
- 接入仍需手工：要么在代码里接 SDK，要么把应用 `base_url` 指向本地录制代理。一键埋点与 Anthropic 协议尚未支持（代理只绑 `127.0.0.1`、仅 OpenAI-compatible `/v1/chat/completions`）。
- 时间旅行默认 **world-free 重放**；隔离文件续跑是例外（副本世界里真执行写操作）。prompt fork、代理重发、模型 A/B 与隔离续跑都是**真实重跑**，会按 provider 计费。
- 模型 A/B 是**实验对比**，不做「哪个模型更好」的排名；不产出臂间差值或胜出臂结论。
- 批量写盘占用尚无长期管理：隔离快照与共享附件会随 run 累积，清理引用计数尚未实现，重度使用请留意 `data/` 体积。
- 渲染层无 error boundary；代理失败 run 的调用级错误采集等遗留项归后续 change。
- 不做：中间消息任意编辑、span 级 diff、模型 A/B 排名、NSIS 安装包、arm64 构建。
