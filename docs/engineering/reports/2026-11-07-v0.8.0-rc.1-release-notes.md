## 相对 v0.7.0-rc.2 新增

### 1. 界面语言切换（简体中文 / English）

- 设置页新增「界面语言」区，切换**立即生效、无需重启**；语言偏好单独保存，不随模型配置提交。
- 首次启动默认跟随系统语言：中文系统为简体中文，其余为英文。
- 切换会保留未保存的模型输入、草稿与阅读位置；尚未提交的确认（费用 / 副本写入 / 副作用 /
  实验 / 验证）会清零，需按新语言重新核对——这是刻意的 fail-safe，避免跨语言误确认。

### 2. 双语覆盖范围

- **桌面界面**：main/preload/renderer 三层产品文案全覆盖（三栏调试台、时间旅行、文件工作区、
  比较、实验、验证、录制代理、设置与错误边界）。
- **MCP 十三工具**：受控错误、摘要与启动诊断双语；服务启动语言支持 `--locale zh-CN|en-US` 与
  `REBASEAGENT_LOCALE`。
- **CLI**：trace-test 人类报告与配置错误、model-ab 人类输出双语；共享解析优先级
  `--locale` > `REBASEAGENT_LOCALE` > 系统语言 > en-US，非法值受控退出（INVALID_LOCALE）。
- **发行 zip**：使用说明中英双语（`使用说明.txt` / `使用说明.en.txt`）。
- 逐场景证据与限制登记见 `add-software-i18n` 归档 evidence-index §6.7；主 spec 新建 `software-i18n`。

### 3. 工程备注：不做 Linux / macOS 包

经评估本轮**不**补打 Linux/macOS 版（无法从 Windows 交叉构建、发行管线绑死 Windows portable
exe、测试跨平台行为未知）；结论与依据见[评估记录](../notes/2026-11-07-cross-platform-packaging-assessment.md)。

## 这版能做什么（沿用 0.7.0 口径 + 双语）

- **录制 — trace 格式 v1 / v2 / v3**：JSONL 事实源，一 run 一文件，append-only；旧版本照旧可读。
- **执行 — 纯 TypeScript 的 Agent 执行引擎**：OpenAI 兼容协议直连，零厂商 SDK。
- **零摩擦录制 — 本地 LLM 录制代理**：key 仅暂存内存、不落盘、不回传渲染层。
- **查看 — 三栏调试台**：概览、步骤、文件页与 span 时间线；状态徽标全界面一个判据。
- **时间旅行（四种改法）**：改某步 `tool_result` 从该步重跑；隔离文件续跑；prompt fork；代理 messages 重发。
- **隔离 prompt 实验（R2.2）**：根初始快照上的单变量实验、v3 记录、跨运行比较与单侧导出。
- **隔离项目验证（R3）**：Docker Desktop 受限容器、`node-ts-v1` 固定模板、准备/执行分开授权、双验证比较与精确输入导出。
- **MCP 只读诊断（十三工具）**：运行、检查点与 R3 验证记录查询；只读、零写入、64 KiB 预算与认证游标。
- **文件阅读与导出、模型 A/B、多分支对照、缓存记账、预算地图、草稿保护、操作追踪、部分运行读取**：沿用已交付口径。

## 已知限制（诚实声明）

- **本版自动化门禁与离线冒烟全绿**（desktop 234 文件 / 3588 用例；zip 组装三段自验、解压后
  十三工具自跑、打包后离线冒烟 12 判据全过），**§9.1 人工实机验收未执行**；语言切换的实机
  走查与 R3 面板的视觉/键盘/窄窗/200% 取证尚未完成。
- **发行 zip 尚未上传**：tag 本地已建未推，链接在维护者上传前不可用。
- **R3 只声明模板范围**：仅 Windows x64 + Docker Desktop（Linux containers）+ `node-ts-v1`；
  真实项目接入（I 组 7.1/7.2）未排期；不支持 WSL / 远程 Docker / Podman。
- **R3 不自动发起模型修复**：修复必须来自已记录的运行分支。
- **MCP 需要 Node ≥ 20**；首次使用前先启动一次桌面主程序生成 `data/` 目录。
- **不透传 `structuredContent` 的客户端（含 WorkBuddy / Trae）看不到 MCP 续读游标**。
- **CLI 语言边界**：`--report json` 等结构化输出语言无关；非法 locale 在执行前受控退出。
- **UI 未显示版本号**：核验版本请比对 zip 内 `SHA256SUMS.txt` 的 exe SHA-256。
- 仅构建 Windows x64；隔离续跑、prompt fork、代理重发、模型 A/B 与隔离 prompt 实验都是真实重跑，
  会按 provider 计费；R3 验证与 MCP 查询本身零模型调用。
- 本版 zip 约 105.8 MB（主因 `mcp/` 依赖闭包与 i18n 资源）；**超出 Gitee 单附件上限，Gitee 页不直挂附件、下载走 GitHub**。若后续需恢复 Gitee 直挂，须先把 zip 压回 100 MB（约 96 MiB）以内（候选手段：`mcp/` 闭包瘦身或压缩等级调整），并重新记录哈希。
