## 构建坑与边界（本轮实测）

1. **worktree 检出 CRLF**：仓库 `.gitattributes` 只覆盖 `*.ts/tsx/js/cjs/mjs/json`，
   **漏 `*.css`**——全新检出时 `index.css` 被 PortableGit 系统级 `core.autocrlf=true` 转成 CRLF，
   biome format 报错（主仓文件历来是工具直写 LF 所以从未暴露）。
   处置：worktree 内将该文件转回 LF（与 index blob 一致，`git diff` 为空）；
   并已为本仓设置 `core.autocrlf=false`（写入共享 `.git/config`，index 全 LF 无副作用，
   主仓同样受益）。**建议后续给 .gitattributes 补 `*.css text eol=lf`**（本轮未动，避免扩 scope）。
2. **worktree 无 node_modules**：`pnpm install --frozen-lockfile` 时 esbuild 三版本的 postinstall
   自检（`spawnSync node.exe`）被沙箱 EBUSY 拦死（确定性），二进制本体（`@esbuild/win32-x64`）无恙；
   以 `--ignore-scripts` 收口安装后 esbuild 运行时解析正常。electron 的 postinstall（联网下载）
   同样未跑——打包走 `-c.electronDist=D:/ReBaseAgent/.rebaseagent/electron-dist` 离线缓存，无需它。
3. **`git checkout-index -f -a` 未能改写行尾**（stat 缓存短路），最终以 node 逐文件转换；
   `git status` 一度显示 index.css 为 M，刷新后 diff 为空、状态干净。
