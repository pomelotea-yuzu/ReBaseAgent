# ReBaseAgent v0.3.0-k0 预览版 — 模型 A/B 实验 · 原生建运行 · 缓存记账 · 失败详情

> **本版是预发布体验包（K0），不是正式发行。** 已在 Windows x64 上完成完整实机验收：
> 构建与自动化通过、五项实机验收通过、六项桌面能力核对 **6/6** 通过。
> 仍**不含隔离文件重跑**（该能力尚在开发，见"已知限制"）。

Agent 的时间旅行调试器。不止回放 Agent 做了什么，而是让你改变它做了什么。

Agent 跑歪时，bug 往往不在你的 loop 代码里，而在某一步的上下文里。云端平台能看但数据出境，本地抓包工具只读不可改。ReBaseAgent 让你回到跑歪的那一步，改掉脏掉的上下文，只重跑必要的那段 —— 全程本地，数据不出机器。

v0.2.0 补齐了「零摩擦接入」与「完整时间旅行」。v0.3.0-k0 是它的增量预览：补上**模型 A/B 实验**这条探索路径，再加上三件日常起手就会用到的事 —— **不用外部应用也能直接建一次运行**、**看得见前缀缓存省了多少**、**失败不再只有一句报错**。

## 相对 v0.2.0 新增

**模型 A/B 与分支实验** —— 同一个启动上下文、多条 arm 并排跑（最多 4 臂，换 model 或换采样参数皆可）。
先点「校验并预览计划」出 dry-run：**不联网、不写文件**，只校验参数并给出费用预估；确认后才按臂数真实调用。
执行完各臂各自落盘为独立轨迹、共享同一个 `experimentId`，分支树按「换 model/params（A/B）」标签归组。
单臂失败不影响其它臂。

**原生运行创建** —— 不必先接 SDK 或开录制代理，桌面内就能直接建一次运行跑起来。

**缓存记账** —— 前缀缓存命中 / 未命中的 tokens 单独记账并可视化。
这是「重跑为什么便宜」的关键证据：改一步重跑，前缀全部本地命中，只有分支点之后才真正调 API。
缺数据的运行显示「未知」，不伪装成零命中。

**LLM 失败详情** —— 调用失败不再只有一句报错：失败标记、错误详情区、脱敏落盘，重启后仍可查。

**代理录制 run 可作分叉父本** —— 代理录下的 run 现在能直接编辑 `messages`、经代理用最近捕获的 key 重发，
单请求级最小分叉（与 tool_result 重跑、prompt fork 相互独立）。

**Provider 原始参数透传** —— 请求体里的扩展参数（`temperature` / `top_p` 等）被完整录制，
重发时原样保留，并附参数生效性自检。

> 另含一项不影响交互的工程改动：发行身份改为**可辨认且不冲突的版本标识**（本版即可用 `0.3.0-k0` 这类标识，
> 不再与上一版共用文件名）。

## 这版能做什么

- **录制 — trace 格式 v1**：JSONL 事实源，一 run 一文件，append-only；配套 `@rebaseagent/trace-sdk` 埋点。代理录制的 run 额外带 `source` 元数据（向后兼容、不改格式版本）。
- **执行 — 纯 TypeScript 的 Agent 执行引擎**：OpenAI 兼容协议直连（DeepSeek / GLM / Qwen / Kimi 开箱即用），零厂商 SDK。
- **零摩擦录制 — 本地 LLM 录制代理**：在你自己的应用里只改一行 `base_url` 指向 `127.0.0.1:18787/v1`，API key 一字不动，代理透明转发每一次 `chat/completions` 请求并录成 trace。key 仅暂存于内存、不落盘、不回传渲染层。录制 / 看时间线 / 编辑 messages 纯本地；只有「重发」才需要 key。
- **查看 — 桌面调试台**：span 时间线逐步回看每一步模型当时看到的完整上下文；分支树视图（SVG 家谱，节点 = 一次 run、边 = 一次分叉，选中某 run 时高亮根到它的整条祖先链）。
- **预算地图**：token 花在哪了，按消息 / 工具分布可视化。
- **时间旅行（完整切片）**：三种改法，互不冲突——
  - (a) **改某步 tool_result 从该步重跑**：前缀全部本地命中，只有分支点之后才真正调 API；
  - (b) **prompt fork**：编辑 system_prompt 或首条 user_message，从头重跑一条独立新轨迹（与 tool_result replay 正交，不拼接父 spans）；
  - (c) **代理 messages 重发**：代理录下的 run 可直接编辑 messages 经代理用暂存 key 重发，单请求级最小分叉。
- **多分支对照**：勾选最多 4 个分支并排比较状态 / 步数 / tokens / 耗时 / 分叉点 / 共同祖先与相对增量，A/B 探索不再靠记忆来回切。

> 类比传统调试器：上下文预算地图是 Profiler，改 tool_result 重跑是「改一行代码重跑」，分支树 + 多分支对照是「并排看两个分支的代价与结局」，轨迹回放是回归测试。

## 已知限制（诚实声明）

- **本版不含隔离文件重跑** —— 该能力尚在开发，不要按它来评估本包。
- 目前只构建了 **Windows x64**，macOS / Linux 尚未出包。
- 接入仍需手工：要么在代码里接 SDK，要么把应用 `base_url` 指向本地录制代理（零 key 改动）。一键埋点与 Anthropic 协议尚未支持（代理只绑 `127.0.0.1`、仅 OpenAI-compatible `/v1/chat/completions`）。
- 时间旅行默认 **world-free 重放**：工具失败 → 把录下的 tool_result 喂回模型，trace 内自洽；带副作用的工具默认不真重跑，外部状态源（RAG / 记忆 / 数据库）不承诺回退。prompt fork、代理重发与模型 A/B 真实执行都是**真实重跑**，会按 provider 计费。
- 模型 A/B 是**实验对比**，不做「哪个模型更好」的排名。
- 没有真实可复现链路实测前，**不把「约 1/4 成本」写成确定结论**——前缀缓存命中取决于 provider，结果因人而异。
- 不做：中间消息任意编辑、span 级 diff、模型 A/B 排名、预算地图「手术预览」、NSIS 安装包、arm64 构建。
