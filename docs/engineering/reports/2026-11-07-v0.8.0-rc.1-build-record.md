## 构建坑（本轮）

- **agent 会话拦截层假红（6.6 同源）**：replay junction/symlink 用例在会话内假红 11 例、
  全仓 `check:test` 并行与串行均假红；用户终端全绿。处置：门禁以用户终端为准，本记录如实登记。
- **`D:\.pnpm-store` 写入 EPERM**：`pnpm deploy` 向全局 store 添加 tarball 被会话拦截层挡死
  （重试两轮失败）；处置：本次 deploy 以 `npm_config_store_dir` 指向仓库内
  `.rebaseagent/pnpm-store`（联网补拉闭包后成功）。该偏差仅影响本次组装过程，不影响产物
  （zip 内闭包经探针自验）。
- **探针脚本收帧**：常驻 stdio 服务不退出，「收齐即判」必须挂在 data 事件而非进程 exit
  （与 mcp-server stdio-fixtures 同一纪律）。

## 回退方法

`0.7.0-rc.2` 的 exe/zip 在 `release/stable/` 原样保留（哈希见上）。i18n 为纯新增层，
rc.2 的功能与数据格式不受影响；如 rc.1 出现新问题，回退 rc.2 无数据兼容成本。
