Agent 的时间旅行调试器。不止回放 Agent 做了什么，而是让你改变它做了什么。

Agent 跑歪时，bug 往往不在你的 loop 代码里，而在某一步的上下文里。云端平台能看但数据出境，本地抓包工具只读不可改。ReBaseAgent 让你回到跑歪的那一步，改掉脏掉的上下文，只重跑必要的那段 —— 全程本地，数据不出机器。

v0.3.0-k0 把「模型 A/B / 原生建运行 / 缓存记账 / 失败详情」打了包。**v0.3.0-k0-a3.1 补上了这条产品线上最关键、也最难的一块：隔离文件重跑** —— 之前「改某步 tool_result 重跑」对**带写文件的工具**只能退回录制结果，现在它真的在一个隔离副本世界里重跑，而你的源目录一个字节都不会变。

## 相对 v0.3.0-k0 新增：隔离文件重跑（三段）

**① 桌面新建「隔离文件运行」** —— 新建对话框里多一个隔离模式：用**原生目录选择器**挑一个源目录，
应用签发一次性、15 分钟有效的授权令牌，随后从这个目录建出一条**带文件检查点**的隔离 run。
每条 run 的每一轮结束都记下一份目录清单与哈希；附件按**内容寻址**（`workspace-blobs/sha256/…`）、
跨 run 共享，所以整个 `data/` 目录整体拷到另一台机器后照样能读、能分叉。

**② 改某步 `tool_result` → 隔离续跑** —— 选中某轮结束的检查点，改掉那一步的结果，然后续跑。
执行前是**两段式**的：先做一次**只读能力预检**（不联网、不写文件、不消耗任何东西），
把这一轮是不是轮末、源 run 与本地轮号、以及将要写入的副本范围都摊开给你核对确认；
你点确认后才发起真实模型调用。**父 run、源目录、兄弟分支在整条链路中逐字节不变**，
同一轮里兄弟工具的原效果被保留且**不会重放**。

**③ 详情面板的「文件」视图** —— 隔离 run 的详情多了轨迹 / 文件两个页签。
文件页按「本 run 第 N 轮结束」列出该轮结束时**这份 run 自己写过的**文件，
选中即看内容（可搜、可换行），二进制文件只展示体积与哈希、绝不塞进编辑器；
在附件缺失或损坏时给出**文字标签**（不只靠颜色）。**这一视图完全只读 —— 任何形态下都没有回写或应用到源目录的入口。**

导入期就挡住的几类危险输入：源目录里的**链接与 junction**（含「junction 指向磁盘根」这类伪装）、
超过配额的输入、以及路径结构非法的清单，一律拒绝而不是将就。

## 这版能做什么

- **录制 — trace 格式 v1 / v2**：JSONL 事实源，一 run 一文件，append-only；配套 `@rebaseagent/trace-sdk` 埋点。v2 在 `agent.step` 上带**文件检查点**字段，v1 数据照旧可读（两个版本严格匹配，字段错配即拒）。
- **执行 — 纯 TypeScript 的 Agent 执行引擎**：OpenAI 兼容协议直连（DeepSeek / GLM / Qwen / Kimi 开箱即用），零厂商 SDK。
- **零摩擦录制 — 本地 LLM 录制代理**：在你自己的应用里只改一行 `base_url` 指向 `127.0.0.1:18787/v1`，API key 一字不动，代理透明转发每一次 `chat/completions` 请求并录成 trace。key 仅暂存于内存、不落盘、不回传渲染层。
- **查看 — 桌面调试台**：span 时间线逐步回看每一步模型当时看到的完整上下文；分支树视图（SVG 家谱，节点 = 一次 run、边 = 一次分叉，选中时高亮根到它的整条祖先链）；**隔离 run 另有文件视图**（见上）。
- **预算地图**：token 花在哪了，按消息 / 工具分布可视化。
- **时间旅行（四种改法，互不冲突）**：
  - (a) **改某步 `tool_result` 从该步重跑**：前缀全部本地命中，只有分支点之后才真正调 API；
  - (b) **隔离文件续跑**：带写工具的 run 在**隔离副本世界**里真重跑，源目录与父 run 逐字节不变；
  - (c) **prompt fork**：编辑 system_prompt 或首条 user_message，从头重跑一条独立新轨迹；
  - (d) **代理 messages 重发**：代理录下的 run 可直接编辑 messages 经代理用暂存 key 重发，单请求级最小分叉。
- **模型 A/B 实验**：同上下文多臂并排（最多 4 臂，换 model 或换采样参数皆可）。先 dry-run（不联网、不写文件），确认后按臂数真实调用；各臂独立落盘、共享 `experimentId`，分支树按「换 model/params（A/B）」归组。
- **缓存记账**：前缀缓存命中 / 未命中的 tokens 单独记账并可视化；缺数据的运行显示「未知」，不伪装成零命中。
- **LLM 失败详情**：失败标记、错误详情区、脱敏落盘，重启后仍可查。
- **多分支对照**：勾选最多 4 个分支并排比较状态 / 步数 / tokens / 耗时 / 分叉点 / 共同祖先与相对增量。

> 类比传统调试器：上下文预算地图是 Profiler，改 tool_result 重跑是「改一行代码重跑」，
> **隔离文件续跑是「带副作用的操作也能安全回滚重跑」**，分支树 + 多分支对照是「并排看两个分支的代价与结局」，
> 轨迹回放是回归测试。

## 已知限制（诚实声明）

- **隔离链路的适用范围**：只有**带文件检查点的隔离 run** 能进（旧 trace 会明确被拒）；隔离 run 作为父本时 **prompt fork 与模型 A/B 都不可用**（这是刻意的，避免把隔离世界和从头重跑混在一起）。
- **文件视图是只读的**，且只列出**本 run 自己写过的**步骤；不提供导出、跨 run 文件 diff，也不从源目录补历史。
- 文件能力**尚无「按 fixture 哈希逐份核对真实文件 diff」的端到端冒烟**，这一层验证仍在后续范围。
- 目前只构建了 **Windows x64**，macOS / Linux 尚未出包。
- 接入仍需手工：要么在代码里接 SDK，要么把应用 `base_url` 指向本地录制代理。一键埋点与 Anthropic 协议尚未支持（代理只绑 `127.0.0.1`、仅 OpenAI-compatible `/v1/chat/completions`）。
- 时间旅行默认 **world-free 重放**：带副作用的工具默认不真重跑；**隔离文件续跑是例外**，它会在副本世界里真执行写操作，但只作用于副本。prompt fork、代理重发、模型 A/B 与隔离续跑都是**真实重跑**，会按 provider 计费。
- 模型 A/B 是**实验对比**，不做「哪个模型更好」的排名。
- 没有真实可复现链路实测前，**不把「约 1/4 成本」写成确定结论** —— 前缀缓存命中取决于 provider。
- 批量写盘占用尚无长期管理：隔离快照与共享附件会随 run 累积，**清理引用计数尚未实现**，重度使用请留意 `data/` 体积。
- 不做：中间消息任意编辑、span 级 diff、模型 A/B 排名、预算地图「手术预览」、NSIS 安装包、arm64 构建。
