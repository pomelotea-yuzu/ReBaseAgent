## 正文（从 `# ReBaseAgent` 复制到 `MIT License`）

# ReBaseAgent v0.3.0-k1 预览版 — 运行工作区重构：三栏工作台 + 文件阅读，把调试台变成"用得住"的工具

Agent 的时间旅行调试器。不止回放 Agent 做了什么，而是让你改变它做了什么。
Agent 跑歪时，bug 往往不在你的 loop 代码里，而在某一步的上下文里。云端平台能看但数据出境，本地抓包工具只读不可改。ReBaseAgent 让你回到跑歪的那一步，改掉脏掉的上下文，只重跑必要的那段 —— 全程本地，数据不出机器。

## 相对 v0.3.0-k0-a3.1 新增（一）：运行工作区重构（U1）
**① 三栏可调工作台** —— 界面重组为「导航 / 运行目录 / 详情」三栏：导航栏宽 220–360px、
目录栏宽 200–320px、详情区保底 480px，全部可拖拽调节并记忆宽度；
窗口太窄时自动折叠辅助栏（**折叠不写回你的偏好**，拉宽后原样恢复）。
**② 概览页** —— 新增独立概览：这条 run **自己**的结果与消耗一眼看全（状态、步数、tokens、耗时），
不再需要在一长条详情里翻找。
**③ 独立文件页** —— 工作区文件从详情面板里拆出来，成为与概览、详情并列的一等视图，
按"阅读任务"组织，文件多也不再和步骤轨迹搅在一起。
**④ 状态口径统一** —— 运行状态徽章全界面一个判据：`completed` 显示「已结束」、
`crashed` 用中性色（不再假装是失败）、**工具自身的错误不再污染运行状态**；
分支对比面板的状态列同判据。看徽章不用再猜。
**⑤ 短 ID 与复制** —— 列表里的运行 ID 显示为短形态节省空间，但**复制永远给完整 ID**——
贴日志、贴 issue 不会再出现"半截 ID 对不上"。
**⑥ 空状态讲人话** —— 列表为空时区分"目录里确实没有 run"和"数据目录配错了"两种成因，
分别给出对应指引，不再一律显示空白。
**⑦ 编辑器按需加载** —— Monaco 代码编辑器改为懒加载：纯浏览路径（列表/概览/轨迹）
**完全不加载编辑器资源**，打开更快；只有真正进入编辑场景（编辑 tool_result）才装配。
懒边界只透传 `data-*`/`aria-*` 与行为属性，编辑器行为不被外壳污染。
## 相对 v0.3.0-k0-a3.1 新增（二）：文件阅读升级（U2）
**① 检查点与导航控件** —— 文件视图的检查点选择器升级：每轮结束的快照可选择、
可沿导航控件在轮次间切换；重启应用后仍可查看文件差异；
文件读取走独立 IPC 通道并**拒绝一切越权路径**（清单外路径、物理 blob、伪造祖先一律 `not_found` / `step_not_found`）。
**② 会话内恢复阅读位置** —— 文件列表的滚动位置、当前打开的文件：切到别处再回来**原样恢复**；
目标文件失效（run 换了、文件没了）时**明确报失效**，绝不静默换成别的内容冒充。
**③ 目录按真实变化筛选 + 路径查找** —— 文件目录可按"这一轮**真的变过**"筛选
（`diffCount` 从真实数据现算，不再写死），长清单里有路径查找入口，61 个文件也能一秒定位。
**④ 布局按内容容器宽度自适应** —— 这是本版打磨最重的一块：
宽屏两侧并排 diff、中屏转单侧 inline、**窄档（≤800px）目录自动收起**给正文让路；
「inline 文字区 ≥480px」的下限在 ≥960px 视口实测成立；档位横跨 640–1440px 六档，
每档的视口/DPR/文字区宽度都在实机上量过。缩窄时宽度偏好**降级不丢失**，恢复宽档后**原样复原**。
**⑤ 工具操作完整原文且保持只读** —— 长文件**完整加载不截断**（此前超长会折叠）；
查找高亮与命中计数、换行切换、复制按钮全部可用；编辑器全程只读——
**任何形态下都没有回写或应用到源目录的入口**。
**⑥ 两侧读取状态真实** —— 单侧文件视图对"可读侧 / 不可读侧"分别诚实标注
（二进制给体积与完整哈希、不可用侧禁用并给原因），两侧都不可读时**不渲染伪空编辑器**；
快速连续切换目标时**旧响应绝不覆盖新选择**（请求级竞态守卫）——
"点了 A 却显示 B 的内容"这类问题在机制上被挡住。
## 这版能做什么
- **录制 — trace 格式 v1 / v2**：JSONL 事实源，一 run 一文件，append-only；v2 在 `agent.step` 上带文件检查点字段，v1 照旧可读（两版本严格匹配，字段错配即拒）。
- **执行 — 纯 TypeScript 的 Agent 执行引擎**：OpenAI 兼容协议直连（DeepSeek / GLM / Qwen / Kimi 开箱即用），零厂商 SDK。
- **零摩擦录制 — 本地 LLM 录制代理**：应用里改一行 `base_url` 指向 `127.0.0.1:18787/v1`，API key 一字不动；key 仅暂存内存、不落盘、不回传渲染层。
- **查看 — 三栏调试台**（本版重构）：导航 / 目录 / 详情三栏可调；概览页看结果与消耗；独立文件页；span 时间线逐步回看每一步模型当时看到的完整上下文；分支树视图（SVG 家谱，选中高亮祖先链）；状态徽章全界面一个判据。
- **文件阅读**（本版升级）：检查点快照选择与导航、按真实变化筛选、路径查找、按宽度自适应的并排/inline diff、完整原文 + 查找/换行/复制、会话内恢复阅读位置、两侧状态诚实标注 —— 全程只读。
- **预算地图**：token 花在哪了，按消息 / 工具分布可视化。
- **时间旅行（四种改法，互不冲突）**：
  - (a) **改某步 `tool_result` 从该步重跑**：前缀全部本地命中，只有分支点之后才真正调 API；
  - (b) **隔离文件续跑**：带写工具的 run 在隔离副本世界里真重跑，源目录与父 run 逐字节不变；
  - (c) **prompt fork**：编辑 system_prompt 或首条 user_message，从头重跑一条独立新轨迹；
  - (d) **代理 messages 重发**：代理录下的 run 可编辑 messages 经代理重发，单请求级最小分叉。
- **模型 A/B 实验**：同上下文多臂并排（最多 4 臂），先 dry-run 确认后真实调用；分支树按「换 model/params」归组。
- **缓存记账**：前缀缓存命中/未命中单独记账；缺数据显示「未知」，不伪装成零命中。
- **LLM 失败详情**：失败标记、错误详情区、脱敏落盘，重启后仍可查。
- **多分支对照**：最多 4 个分支并排比较状态 / 步数 / tokens / 耗时 / 分叉点（状态列与全局同判据）。
> 类比传统调试器：上下文预算地图是 Profiler，改 tool_result 重跑是「改一行代码重跑」，
> 隔离文件续跑是「带副作用的操作也能安全回滚重跑」，分支树 + 多分支对照是「并排看两个分支的代价与结局」，
> 轨迹回放是回归测试 —— **这版做的是把 IDE 本身从"能用的命令行"升级成"顺手的工作台"**。
## 已知限制（诚实声明）
- **本版主线是"看"不是"跑"**：U1/U2 重构的是工作区与文件阅读的呈现层；
  隔离重跑、A/B、fork 等执行链路的能力边界与 `v0.3.0-k0-a3.1` 完全一致（见该版声明）。
- **文件视图仍然只读**，且只列出**本 run 自己写过的**文件；不提供导出、跨 run 文件 diff，也不从源目录补历史（结果导出在下一步路线里）。
- **窄档的边界很较真但很诚实**：≤800px 视口会收起目录，这是刻意设计；「inline 文字区 ≥480」只在 ≥960px 视口成立，960px 以下不承诺 480。
- 概览页对"思维链分区展示"的覆盖目前是契约级验证，带真实 `reasoning_content` 的实机截图验收仍在清单上。
- 目前只构建了 **Windows x64**，macOS / Linux 尚未出包。
- 接入仍需手工：要么在代码里接 SDK，要么把应用 `base_url` 指向本地录制代理。一键埋点与 Anthropic 协议尚未支持（代理只绑 `127.0.0.1`、仅 OpenAI-compatible `/v1/chat/completions`）。
- 时间旅行默认 **world-free 重放**；隔离文件续跑是例外（副本世界里真执行写操作）。prompt fork、代理重发、模型 A/B 与隔离续跑都是**真实重跑**，会按 provider 计费。
- 模型 A/B 是**实验对比**，不做「哪个模型更好」的排名；「约 1/4 成本」取决于 provider 的前缀缓存命中，不作确定结论。
- 批量写盘占用尚无长期管理：隔离快照与共享附件会随 run 累积，**清理引用计数尚未实现**，重度使用请留意 `data/` 体积。
- 不做：中间消息任意编辑、span 级 diff、模型 A/B 排名、预算地图「手术预览」、NSIS 安装包、arm64 构建。
