# ReBaseAgent v0.6.0-rc.1 发行候选 — MCP 只读诊断、隔离 prompt 实验与渲染层重构

Agent 的时间旅行调试器。不止回放 Agent 做了什么，而是让你改变它做了什么。

Agent 跑歪时，bug 往往不在你的 loop 代码里，而在某一步的上下文里。云端平台能看但数据出境，本地抓包工具只读不可改。ReBaseAgent 让你回到跑歪的那一步，改掉脏掉的上下文，只重跑必要的那段 —— 轨迹保存在本地，真实模型请求按你的配置发往服务商。**本版起，你正在用的 AI 工具（WorkBuddy / Trae / Cursor 等 MCP 客户端）也能直接查询这些运行记录**，全程只读。

## 相对 v0.5.0-rc.1 新增（一）：MCP 只读诊断（MCP0 + MCP1）

zip 附带自包含的 `mcp/` 目录 —— 让支持 MCP 的 AI 客户端**只读查询**你的运行记录，不重跑、不写盘、不执行工具、不调用模型。

- **七个只读工具**：运行清单、运行详情、步骤正文（input/output/error）、两侧比较、检查点清单、检查点文件读取、两侧文件比较；无 prompts/resources 旁路，工具声明带只读标注。
- **接入一行配置**：客户端 MCP 设置里加 stdio 服务 `node <解压目录>\mcp\dist\cli.js --data-dir <解压目录>\data`（需 Node ≥ 20；WorkBuddy 自带）。完整指南随仓库发布（`docs/guide/mcp-readonly-diagnostics.md`），含能力边界、费用与已知限制。
- **引用可回查（真实客户端验收）**：结果里的事实（运行 ID、路径、哈希、错误消息、正文）模型可逐字引用 —— 已在 WorkBuddy 5.9.0 完成代表任务两轮验收（错误运行定位 → HTTP 503 错误消息原文 → 检查点文件清单与正文 → 两侧比较），并在 Trae 3.4.4 复验。
- **只读是验出来的，不是声明的**：查询前后数据根逐文件指纹不变（两轮实测零变化）；凭据字段过滤（`Authorization`/`api-key` 等替换为 `[REDACTED]`）；完整结果 64 KiB 预算、按码点截断、认证游标续读；断连重连只是重新查询、取消零副作用。
- **桌面主程序不受影响**：exe 不内嵌 MCP，单独流传时桌面功能完整。

## 相对 v0.5.0-rc.1 新增（二）：隔离 prompt 实验（R2.2）

把「换一句 prompt 会不会更好」变成**可验证的单变量实验**，而不是凭感觉重跑。

- **根初始快照上的隔离实验**：从同一条基线（父 run 的初始状态）改 system prompt 或模型参数，各自在隔离副本世界里从头重跑 —— 源目录与父 run 逐字节不变；实验身份、执行参数、配置指纹全记录（trace v3）。
- **跨运行检查点与文件比较**：实验臂与基线、不同实验之间逐检查点对比文件清单与内容；两侧身份各归其列，缺一侧不发半份结论。
- **单侧导出**：把任意一侧（基线或实验臂）的检查点快照导出带走，与 0.5.0 的整目录导出同一套确认与哈希复核口径。
- **诚实边界**：隔离父本/分支上的 prompt fork 与模型 A/B 仍禁用（R2.2 只开放根初始快照）；二进制与超限逐侧状态由单元测试承载；视觉可读性待发行前人工验收。

## 相对 v0.5.0-rc.1 新增（三）：渲染层模块重构（内部）

63 个巨型组件文件收敛为「store 组合层 + 连接层」（如 `store.ts` 3769 行 → 135 行），**行为零变化** —— 由 6 个实机批次与全量门禁背书（desktop 216 文件 / 3301 用例）。对使用者不可见，为后续 UI 能力降耦合。

## 这版能做什么

- **录制 — trace 格式 v1 / v2 / v3**：JSONL 事实源，一 run 一文件，append-only；v2 在 `agent.step` 上带文件检查点字段，v3 带隔离实验身份，旧版本照旧可读。
- **执行 — 纯 TypeScript 的 Agent 执行引擎**：OpenAI 兼容协议直连（DeepSeek / GLM / Qwen / Kimi 开箱即用），零厂商 SDK。
- **零摩擦录制 — 本地 LLM 录制代理**：应用里把 `base_url` 指向本地代理即可录制；key 仅暂存内存、不落盘、不回传渲染层；上游写失败如实落 span 并保留草稿。
- **查看 — 三栏调试台**：导航 / 目录 / 详情三栏可调，支持专注模式；概览页看结果与消耗；独立文件页；span 时间线逐步回看每一步模型当时看到的完整上下文；状态徽标全界面一个判据。
- **文件阅读与导出**：检查点快照选择与导航、按真实变化筛选、路径查找、按宽度自适应的并排/inline diff、完整原文 + 查找/换行/复制、会话内恢复阅读位置、两侧状态诚实标注；选中检查点可整目录导出带走；**实验臂可单侧导出（本版新增）**。
- **隔离 prompt 实验（本版新增）**：同基线、单变量、隔离副本世界真实重跑；跨运行检查点/文件比较；实验身份与参数全记录。
- **MCP 只读诊断（本版新增）**：见上节 —— 外部 AI 客户端查运行清单、步骤正文、比较与检查点文件。
- **预算地图**：token 花在哪了，按消息 / 工具分布可视化。
- **时间旅行（四种改法，互不冲突）**：
  - (a) **改某步 `tool_result` 从该步重跑**：前缀全部本地命中，只有分支点之后才真正调 API；
  - (b) **隔离文件续跑**：带写工具的 run 在隔离副本世界里真重跑，源目录与父 run 逐字节不变；
  - (c) **prompt fork**：编辑 system_prompt 或首条 user_message，从头重跑一条独立新轨迹；
  - (d) **代理 messages 重发**：代理录下的 run 可编辑 messages 经代理重发，单请求级最小分叉。
- **模型 A/B 实验**：同上下文多臂并排（最多 4 臂），先校验并预览计划（费用确认）后真实调用；结果按批次分组、跨页存活。
- **多分支对照**：宽幅指标表 + 详细比较页 + 分支树，最多 4 条分支并排；比较对象身份清晰、切换不重载。
- **缓存记账**：前缀缓存命中/未命中单独记账；缺数据显示「未知」，不伪装成零命中。
- **调试草稿保护**：会话内按编辑身份保存、退出确认、活动条跨页定位。
- **操作追踪**：主动操作登记、幂等键、终态信封与结果 run ID、结果待看计数。
- **部分运行读取**：父链缺失时结构化降级，缺失项不补零、不推算，恢复后全量重验。

> 类比传统调试器：结果导出是「把复现材料打包给同事」，上下文预算地图是 Profiler，改 tool_result 重跑是「改一行代码重跑」，隔离文件续跑是「带副作用的操作也能安全回滚重跑」，隔离 prompt 实验是「固定其余变量只改一个输入的对照实验」，MCP 只读诊断是「把断点上下文开放给你其它的调试工具」。

## 已知限制（诚实声明）

- **本版自动化门禁与离线冒烟全绿（desktop 216 文件 / 3301 用例；zip 组装三段自验与解压自跑通过；打包后离线冒烟 12 判据全过），§9.1 人工实机验收未执行**；需要时按既有清单口径补验。
- **MCP 需要 Node ≥ 20**（部分客户端自带；zip 不携带 Node 运行时）；首次使用前先启动一次桌面主程序生成 `data/` 目录。
- **不透传 `structuredContent` 的客户端（含 WorkBuddy / Trae）看不到 MCP 续读游标**：超大文件只能读首段与清单事实，分页翻页同理（指南 §8 如实说明，属已钉住的客户端行为边界）。
- **执行中的 run 不出现在左侧列表**，完成后才出现——这是列表刷新时机的现行设计。
- **UI 未显示版本号**：窗口标题固定为 ReBaseAgent；核验版本请比对 zip 内 `SHA256SUMS.txt` 的 exe SHA-256。
- 文件视图只读，且只列出**本 run 自己写过的**文件；跨 run 文件比较由实验比较视图承载（R2.2）。
- 目前只构建了 **Windows x64**，macOS / Linux 尚未出包。
- 接入仍需手工：要么在代码里接 SDK，要么把应用 `base_url` 指向本地录制代理。一键埋点与 Anthropic 协议尚未支持（代理只绑 `127.0.0.1`、仅 OpenAI-compatible `/v1/chat/completions`）。
- 时间旅行默认 **world-free 重放**；隔离文件续跑、prompt fork、代理重发、模型 A/B 与隔离 prompt 实验都是**真实重跑**，会按 provider 计费。MCP 查询本身零模型调用；把查询结果发给客户端侧模型的费用由客户端产生。
- 模型 A/B 与隔离 prompt 实验是**实验对比**，不做「哪个模型/哪句 prompt 更好」的排名；不产出臂间差值或胜出臂结论。
- 批量写盘占用尚无长期管理：隔离快照与共享附件会随 run 累积，重度使用请留意 `data/` 体积（本版 zip 亦增至约 100 MB，主因 `mcp/` 依赖闭包）。
- 渲染层无 error boundary；部分遗留项归后续 change。
- 不做：中间消息任意编辑、span 级 diff、模型排名、NSIS 安装包、arm64 构建、内置 Agent 调用外部 MCP 工具、MCP 受控执行（按路线归 MCP3）。
