## 构建坑（本轮新钉，均已绕过）

- **火绒按精确路径拦 electron-builder 缓存工具**：`Cache\7zip@1.0.0\...\7za.exe` 建档与
  `Cache\nsis-3.0.4.1\...\Bin\makensis.exe` 写 exe 均「拒绝访问」（1 MB 也拦；退出主程序
  驱动仍在；用户 PowerShell 同拦 ⇒ 非会话沙箱）。绕法：
  - 7za ⇒ `ELECTRON_BUILDER_7ZIP_PATH=C:\Program Files\7-Zip\7z.exe`（系统签名实例放行）；
  - NSIS ⇒ 整目录拷贝改名后放行 ⇒ `ELECTRON_BUILDER_NSIS_DIR=D:\ReBaseAgent\.rebaseagent\nsis-clean`
    （拷贝需带完整 Bin 依赖，单拷 makensis.exe 会 `0xC0000135` 缺 DLL）。
  - 曾试给 makensis 置 LAA 位（无效，非地址空间问题）。**火绒退出不影响结论：拦截在驱动层。**
- **pnpm deploy 两个坑**：目标必须是仓库内相对路径（仓库外绝对路径下 workspace file: 依赖
  symlink 被拼进包目录）；必须 `--config.node-linker=hoisted`（默认 .pnpm+symlink 布局
  cpSync 会拷断链——SDK 传递依赖 `zod-to-json-schema` 只在 .pnpm，断链在 initialize 才炸；
  symlink 也不能进 zip，Windows 解压需特权）。
- **打包脚本内嵌探针不能用 spawnSync+input**（写完即 EOF，服务端 EOF 退出先于 tools/call
  处理完）⇒ 异步 spawn 一次 write 全帧。
- 组装 zip 用 .NET `ZipFile`（entryNameEncoding=UTF8）：本机 7za 写档被拦 + .NET 默认编码
  会把中文条目名写成 GBK 乱码；列表自验用 `7za l -sccUTF-8`（读不被拦）。
