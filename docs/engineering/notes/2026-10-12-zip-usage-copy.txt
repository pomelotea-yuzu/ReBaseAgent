﻿ReBaseAgent 使用说明
=====================

【这是什么】

ReBaseAgent 是一个 Agent 的时间旅行调试器：录下 AI Agent 的每一次运行，
回看每一步模型当时看到的内容，并能改掉跑歪的那一步、只重跑必要的那段。
所有数据保存在你自己的电脑上。

【运行要求】

- Windows 10 / 11（64 位）
- 无需安装，免管理员权限

【怎么开始】

1. 把压缩包解压到一个固定的文件夹（例如 D:\ReBaseAgent\）。
   建议用 7-Zip 或 WinRAR 解压。
2. 双击文件夹里的 ReBaseAgent-*.exe 即可启动。
3. 首次运行可能弹出「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」。
   （本程序未购买代码签名证书，属个人开源项目，此提示为系统对未签名
   程序的常规提醒；可先用压缩包内 SHA256SUMS.txt 核对文件完整性。）
4. 首次启动会自动在 exe 同级生成 data\ 目录并创建示例运行。

【数据保存在哪里】

- 所有运行记录、设置、配置都存在 exe 同级的 data\ 文件夹里。
- 不写注册表、不写 C:\Users\你\AppData，删掉 data\ 文件夹即彻底清除数据。
- 想备份：直接复制整个文件夹（含 data\）。
- 注意：把 exe 移动到别的目录 = 换了一个新的数据目录，
  原来的数据还在旧目录里。

【怎么升级】

- 下载新版 zip，解压后用新 exe 替换旧 exe（保留同级 data\ 文件夹），
  历史运行数据全部保留。
- 也可以解压到新文件夹从零开始，互不影响。

【模型接入】

- 本程序是调试工具，不自带模型。需要你自己在设置里填入
  OpenAI 兼容协议的服务商（DeepSeek / GLM / Qwen / Kimi 等开箱即用）。
- API Key 只保存在本地，请求由你的电脑直连服务商，
  本程序不经过任何第三方服务器。
- 也可以用内置的「本地录制代理」：让 Agent 应用的 base_url 指向
  本地代理端口，即可边使用边录制，无需改代码。

【常见问题】

Q: 双击提示「Windows 已保护你的电脑」？
A: 点「更多信息」→「仍要运行」。介意的话先用 SHA256SUMS.txt 核对
   文件哈希（命令：certutil -hashfile 文件名 SHA256），与 Release 页
   公布的值一致即可放心。

Q: 杀毒软件报毒 / 提示未签名程序？
A: 未签名程序的常规误报。可将本程序所在目录加入杀毒软件的信任区；
   如仍有顾虑，项目全部源码开源，欢迎自行审查或从源码构建，
   我们也在评估代码签名方案，希望后续版本能带来更顺滑的安装体验。

Q: 关闭窗口时弹出确认框？
A: 有未保存的编辑草稿时的正常保护，确认后才会关闭。

Q: 数据会传到网上吗？
A: 运行记录永远只存本地；只有向模型服务商发起对话时才会联网，
   且按你的配置直连。
