# U7 设计：可信关系与宽幅比较工作区

## Context

动机与范围见 [proposal](proposal.md)。当前 `BranchTree` 使用 `layoutRunTree(buildRunForest(runs))`，节点点击走 `selectRun`，打开详情另走 `setView("trace")`；缩放为局部状态，无搜索/当前树范围/返回视口。`ComparePanel` 固定 `w-64`、每值 `w-14`，ID 使用 `slice(0, 7)`，数据仅来自列表的 `deriveComparison`。

U1 已有 `shared/nav.ts` 的会话稳定短 ID、`shared/outcome.ts` 与 `shared/overview.ts`；U2 已有按 run 的文件检查点/路径恢复与合法性校验；U5 已有导航代次和可信结果 ID；U6 的 `RunDetail` 提供 completeness/spanScope/lineage/leafSpanIds，`readRunLineage` 严格区分祖先缺失与其他错误。比较不得再用列表时间、状态或图上的连线推断这些事实。

## Goals / Non-Goals

在既有数据边界内让用户完成定位分支、选两条、阅读修改和结果、打开对应步骤/文件并返回的闭环。树布局继续纯计算，视口变换单独管理；比较只存会话阅读状态，不建立新的运行结局或操作登记真相源。其余范围见 proposal。

## Decisions

### D1：一个比较工作区，两个独立选择集合

保留全局 `compareIds` 的有序、去重、最多四条集合；详细比较使用独立的 `leftRunId/rightRunId`，不能绑定 `selectedRunId`。手动加入恰好两条时第一条在左、第二条在右，即使先子后父也不自动重排；“与父运行对比”明确父左子右。三四条进入指标表后显式选择两条，进入/交换不改全局集合。单条显示自有指标及再选一条提示，零条显示引导；相同 ID 不构成两条比较。

`WorkspaceView` 增加比较模式，保存类型明确的返回位置：来源视图、run 阅读状态、树视口/搜索/范围/图或列表模式、焦点目标。进入/退出/更换比较对象均作为 U5 的显式导航意图推进代次，阻止在途操作完成后抢走比较页。比较对象变更不调用 `selectRun`；明确“打开运行/调用/文件”才走现有导航，返回比较恢复对象、页签、单侧调用与滚动。返回目标已失效时解释并落到仍有效来源，不选同名运行。

拒绝继续加宽原 256px 侧栏：正文和四条指标需要独立可用宽度。也不以每次开比较清空工作区状态换取简单实现，这会重现 U1/U2 阅读丢失。

### D2：树的逻辑坐标与视口分离

沿用确定性森林和 SVG 边，统一固定节点布局常量容纳任务摘要、唯一短 ID、模型、状态、时间及自有步数/tokens；长字段在选中详情区完整展开/复制，沿链累计放到详情区，不继续塞进不足高度的节点。节点/边摘要完整值可用键盘展开。选中边框独立于状态色。

首次进入默认当前 run 所属已知树并将当前节点放入可视区；无当前 run 时显示全部。明确的范围切换、搜索结果定位、适应画布、当前定位及缩放/平移仅改变视口，缩放不改应用字体。搜索匹配完整 ID/任务，范围外命中可显式定位所属树。返回树恢复会话视口，不重复强制居中；显式定位才再次居中。

单击保持既有选择/详情加载语义但不离开树；节点旁详情提供打开和加入/移出对比，双击只是快捷方式。关系列表消费同一森林、身份及选中集合，支持 Tab/Enter/Space，不嵌套交互按钮。父缺失占位只包含真实引用 ID 与原因，不能加入对比或当作有效 run；原 run 仍按既有规则提升为根。成环仍断开标记。实验分组仅用记录 experimentId，跨批同 parent 不伪造成同组。

### D3：按请求形成只读比较快照

增加桌面只读 `runs:compare` / preload `compareRuns`：输入为 1–4 个互异合法 run ID。main/shared/preload/renderer 两端验证输入输出，不接受路径、任意文件引用、客户端自报指标或完整性。无 operationId、执行槽、sourceToken 或确认字段。

单次调用共享按 run ID 缓存的读取上下文：每个物理 run 本次最多解析一次，由 U6 reader/版本/关系校验产出详情和所需祖先的自有摘要。提取读取上下文只改变复用方式，不改变 `runs:get` 或执行拒绝。响应按原请求顺序返回各项 `ready(detail)/unavailable(code, reason)`、已验证祖先摘要、关系/编辑证据及实验资格；关系结论必须与详情及其父链相容。当前文件不可读不能删掉该栏后偷偷换一个对象，其他合法栏仍可单独读。

派生继续复用 `deriveComparison/deriveChainTotals`，但输入来自本次已校验记录的自有摘要；缺项、ownOnly、失败一律撤销对应沿链结论，不能回退到列表缓存。普通 ownOnly 可比较自有事实；共同祖先为判定不完整，受影响累计未知，所有祖先差禁算。另一条完整链自己的累计仍可读。这不是文件系统事务快照：封存记录在正常应用内不可变，外部改动只在下一次显式重读生效；本次已知错误不能被旧缓存掩盖。

renderer 为整个选择集维护 request generation，为每侧保留 run 身份及阅读状态；应用响应前核对 generation、完整有序 ID 集及 schema。快速替换、交换、移出或离开使旧请求失效。重试重新读取整组选中对象以保持共同基线一致，保留未换对象阅读位置；失败展示各侧原因并允许单独打开。刷新明确撤销旧比较结论后再展示新结论，不把旧成功当本次成功。不走 U5 结果收尾、清草稿或执行重发。

### D4：修改证据和步骤来源

修改投影为 `verified / unavailable / notApplicable`，每项带源 run、目标 run、字段和可验证定位。直接父子的新值来自子 fork.edit；原值按字段从已校验父轨迹/请求提取：result 定位 tool.invoke.result，prompt 取实际启动消息，messages 取对应请求 messages，model_params 取实际记录 model/params。缺字段/父本或未知 edit.field 显示原始字段和值及不可核对原因，不填空串、不猜原值。空串、null 和未记录必须区分；工具返回改动不称为文件改动。

多跳和兄弟比较逐跳列出从已确认共同祖先到两侧的来源路径，每跳核对其直接父；不把整条链压缩成一次编辑。不同根不制造编辑关系，只列两侧真实启动输入/记录模型参数的可核对差异，config_hash 不可反推完整配置。左右交换同步方向与所有标题。

输出使用 `deriveOwnOutput` 与同一结局分类，错误定位带 `(runId, spanId)`。两侧正文独立滚动；双方均有真实最终文本时可切只读 Monaco 文本 diff，同步滚动仅适用于此模式。错误、未记录、reasoning-only 不能作为空文本参与 diff；可读一侧仍完整展开、查找、复制。

步骤默认两列独立目录与调用详情。共享前缀通过严格解析的 result 链及已校验分叉边界生成来源映射；映射包含源 run ID 和原 span ID，不能靠两侧重复的 `s_01` 或轮号求交集。v1 保持 span 边界，v2 保持 `resume_after_step` 整轮边界；共同区中被覆写的工具结果仍显示编辑标记，不隐藏差异。跨 prompt/messages/model_params 的 hop 中断共享执行前缀判断。若当前解析不能提供可靠来源映射，最小提取既有 resolver 的只读投影并对照完整轨迹验证，不能另造截断算法。用户可展开完整前缀，折叠不删记录。

### D5：消耗与模型实验门禁

自有指标由每侧 detail 的 leafSpanIds 派生，复用概览的时间/缓存已记录范围和失败占位解释。沿链累计继续明确标注“累计增量（沿链求和）”，相对共同祖先数值为 `该侧累计 − 祖先累计`，不是左右臂相减，不称连续单次总成本。指标表固定名称列，运行列以稳定短 ID、任务、模型和状态标识，内部横向滚动。三四条中选两条不改变其他对象。

含任一 model_params 的选择集先走实验判据：仅全部为已封存 model_params 臂、直接 parent 相同、完整父链且配置/工具校验通过时可进入实验比较；混入普通记录/父本时给出不可比较原因，可分别打开记录。不同 experimentId 不自动拒绝合法同父臂，但分别保留真实批次标签；experimentId 相同也不能覆盖 parent 不同。模型臂“与父运行对比”入口不提供普通比较旁路。

历史比较不重跑当前配置的 dry-run，也不要求当前 API key。main 从已校验记录核对父与臂 config_hash 同源、首请求及 fork.edit model/params 自洽、记录工具表一致、父本类型与已记录副作用声明；复用或提取 replay 中 `derivePromptForkState`、参数与工具策略的纯校验。不能从 hash 反推未录完整 RunConfig，不能把正常封存当作前置校验通过；记录不足以证明某项时资格为不可验证并说明原因。只提取读判据，执行仍沿用原有完整配置、handler、费用确认、权限检查。该最小包层提取须做执行门禁等价回归。

可比较不要求 reason=completed：已封存 error/上限臂仍展示事实，绝不生成胜出结论。副作用放行记录保留顺序执行/外部状态可能变化说明；重启、换 key 或 settings 不让同一历史记录随机变成不同资格。

### D6：文件与响应式边界

比较只显示“打开左侧文件/打开右侧文件”，仅对应隔离运行具备自有文件能力时启用；普通运行不生成历史。调用 U2 显式定位/恢复链，检查点必须属于目标 run 自有清单；从步骤打开时，仅合法自有完成步骤能成为定位目标，否则说明原因并使用该 run 已保存合法位置或 U2 默认位置。父链不完整但自有文件合法仍可打开。返回比较恢复对象和位置，没有“文件比较”页签。

双运行正文容器宽度至少 960 CSS px 时并排，否则上下排列并重复对象标题；该阈值是初始实现常量，可依据实测调整但须满足相同可达性判据。比较首次进入窄窗默认收起导航，退出恢复用户原导航状态。四条表格每运行列保留可读最小宽度、名称列 sticky，横滚只在表格容器内；不能靠压缩字号或应用整体横滚容纳。所有动作有中文可访问名称、焦点状态；交换/加载/重试不重置键盘焦点到页面顶部。

## Risks / Trade-offs

- 多侧完整读取较列表对照昂贵 → 仅进入比较/明确重试时读取选中对象及其祖先，共享上下文，不为绘树批量读详情。
- 老记录无法证明模型实验配置 → 单独事实仍可读，实验比较明确拒绝，不补造通过标记或强迫设置新密钥。
- 既有测试仅静态渲染不能证明滚动/Monaco/键盘 → 纯派生、IPC、store 与 Electron 分层验证，真实 UI 结果单列。
- store 状态扩展易污染共享单例测试 → 同轮补齐所有既有手写复位表与 window.api 桩，整文件通过后再做全量。
- 外部文件变化与快速导航可能交错 → 选择集代次及只读快照双校验；返回位置失效有显式降级。

## Migration Plan

按 tasks 顺序交付派生/读取、导航、树、双运行、多指标/实验及实机验证。无持久化迁移，旧 trace 保持可读；main/preload/renderer 同版本一起部署，功能回退通过代码回退，不改 trace。归档前对三份 MODIFIED delta 做场景名和内容差集核对；新增行为有证据后才合主 spec，本轮不归档。

## 有意修改的既有契约

- branch-tree 的“祖先链即共享前缀”改为来源关系；普通 result 按真实边界单独判定共享执行前缀。
- desktop-ui 视图条款、概览条款和执行流程只读场景解除“未实现比较入口”的阶段限制。保留“非法详情不被概览绕过”场景名，删除其已过时的缺祖先一律报错结论；按 U6 区分已校验 ownOnly 与损坏/版本/权限等严格错误，新增缺祖先概览场景锁定可读自有事实及受限链结论。其余只读/结果语义保留。
- branch-tree 的节点字段清单显式补齐稳定唯一短 ID 与记录模型，与 D2 和完整阅读场景一致；模型缺失标未记录。
- model-experiments 保持可比条件及禁止结论，补齐历史读取的证据判据、混选和缺证拒绝；状态展示和场景使用共用工作区/宽幅指标表名称，不绑定被替换的 ComparePanel 组件。其他既有需求完整保留。
