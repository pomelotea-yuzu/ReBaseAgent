- 任务 7.4 核对全部行名与 delta 一一对应；新增或改名场景同步本表，保留场景不能因局部改文案丢失回归。

- 桌面截图不能替代字节/哈希、IPC 或执行计数；mock 不能作为真实模型修复证据。实机未能诱发的存储/乱序故障注明测试层和限制。

- 每批填入命令与 exit code；最后重跑适用门禁并记录最终源码身份，归档和发行分别核对。
