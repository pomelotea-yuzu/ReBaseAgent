## MODIFIED Requirements

### Requirement: 比较沿用共同祖先和现有派生口径

模型实验 SHALL 复用现有 `deriveComparison` 的共同祖先判定、`deriveChainTotals` 的链路累计，并在共用比较工作区与宽幅指标表中使用一致的状态展示。只有直接 parent 相同、父链完整、run 已封存且配置/工具前置校验通过时，结果才可比较；不得在包层复制指标派生函数。原始 trace 内容 SHALL 保持完整，UI 使用折叠而非截断丢弃。

系统 SHALL 只展示各臂相对父 run 的累计增量，SHALL NOT 产出臂间差值、胜出臂或最佳模型结论；沿链数字沿用既有措辞纪律，禁用"总耗时 / 总成本"。

共用比较工作区 SHALL 对包含 model_params 的选择集应用上述门禁：全部对象为 model_params 臂、直接 parent 相同才可作为实验比较；混入普通 run 或父本不能退回普通比较绕过条件。experimentId 只用于真实分组，同一 experimentId 不能豁免父本/完整性校验，不同批次的合法同父臂可比较但须保留批次身份。已封存不等于正常结束，合法失败臂可以参与事实比较。

历史比较的配置/工具判据 SHALL 从已校验记录核对父与臂 config_hash 同源、fork model/params 与首请求一致、记录工具表及副作用策略自洽；不可从 hash 反推完整配置，也不可把封存当成前置校验已通过。证据不足 SHALL 明确不可验证并禁止实验比较。读取 SHALL 不依赖当前密钥、不运行当前设置的实验预览或执行，不产生新授权；已记录副作用放行 SHALL 保留顺序执行与外部状态影响说明。

#### Scenario: 共同祖先可比

- **WHEN** 两个 model_params fork 均从同一父 run 创建并封存
- **THEN** 共用比较工作区与宽幅指标表判定存在共同祖先，分别展示 outcome、tokens、duration、工具轨迹和各自相对父 run 的累计增量

#### Scenario: 父链缺失或结果未封存

- **WHEN** 任一 arm 的父链断裂、run 未封存或工具策略校验未通过
- **THEN** 共用比较工作区与宽幅指标表显示不可比较及明确原因，不计算增量差值或最佳模型结论

## ADDED Requirements

### Requirement: 共用工作区不能绕过实验比较资格

系统 SHALL 在两条详细比较和最多四条指标表上使用相同实验资格，并对每种拒绝给出可读原因及单独打开记录入口。SHALL 只展示各臂事实及相对父 run 的累计增量，禁止臂间差值、自动评分、胜出臂或最佳模型。

#### Scenario: 合法同父实验臂展示事实

- **WHEN** 两至四条 model_params 臂直接 parent 相同、完整已封存且记录校验通过，其中可含 error/上限结局
- **THEN** 分别展示输出/错误、独立步骤、自有指标及相对父累计增量；合法失败臂不被当正常成功，也不因结局失败自动拒绝事实比较

#### Scenario: 异父混选与相同实验标签不能绕过

- **WHEN** 模型臂直接 parent 不同、与普通 run/父本混选，或只是 experimentId 恰相同
- **THEN** 实验比较明确拒绝，不能套普通不同根规则放行；记录仍可单独打开；不同 experimentId 的合法同父臂不被伪造同批

#### Scenario: 不完整未封存与前置缺证明确拒绝

- **WHEN** 任一臂 ownOnly、未封存、config_hash/首请求/工具表不一致、副作用策略失败或必要证据未记录
- **THEN** 分别给出不可比较或不可验证原因，不生成祖先增量、共享前缀或臂间结论；重试仅重新验证记录

#### Scenario: 历史比较不依赖当前密钥和预览

- **WHEN** 合法历史记录在重启后或当前 API key 清除、当前模型设置变化后读取
- **THEN** 同一记录得出相同实验资格，不要求重新执行 dry-run、不联网、不写文件、不恢复副作用许可，已记录风险提示保留

#### Scenario: 交换和四列均不产出实验臂间结论

- **WHEN** 用户交换两臂、改选两臂或查看四臂消耗
- **THEN** 只展示各臂事实及相对共同父的累计增量，不产生左右相减、胜出臂、最佳模型或公平隔离承诺
