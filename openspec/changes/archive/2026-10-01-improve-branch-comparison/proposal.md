# U7：分支关系与双运行比较

## Why

U1–U6 已归档，分支关系和详情已有可信数据基础，但现有分支树缺少当前分支聚焦与搜索，对照仍挤在 256px 侧栏，只显示指标且使用可能碰撞的 ID 前缀。用户还不能从两次运行直接核对“改了什么、输出变了什么”。

本 change 对应 [U 拆分计划](../../../docs/engineering/plans/2026-09-21-ui-change-split-plan.md) U7、[UI 方案](../../../docs/engineering/plans/2026-09-19-ui-layout-discussion.md) §14/§15.1–15.3 和[走查 R8/R9](../../../docs/reviews/2026-09-21-ui-usability-walkthrough.md)。基线为 U6 归档提交 `40e5dcc`；`desktop-ui` 62 requirements / 324 scenarios。本轮交付 change 文档，功能尚未实施。

## What Changes

- 分支图默认定位当前运行所属的已知树，提供全部关系、搜索、适应画布、缩放、平移及定位当前运行；稳定节点尺寸，完整字段可展开，复用稳定唯一短 ID、模型和状态语义。
- 明确分开选中节点、打开运行、加入对比；提供同数据的键盘关系列表、父缺失占位和真实 experimentId 分组。来源链高亮不再一律称为共享执行前缀。
- 新增宽幅双运行工作区，包含修改与输出、步骤、消耗三种视图；支持更换左右对象、交换和返回来源位置。手动加入恰好两条时按加入顺序确定左右，“与父运行对比”入口默认父左子右，三至四条对照可显式选两条进入。
- 修改展示来自已校验的 fork 和实际调用：直接父子展示可核实原值/新值，多跳展示逐跳来源，不同根只展示可核对的输入/配置差异。最终输出与失败状态复用 U1 自有事实，缺失不借祖先或中间正文补全。
- 普通比较区分共同祖先、不同根、链不完整；共享前缀只按实际 result 分叉语义识别，prompt、proxy messages 和 model_params 保持独立轨迹。同步修正概览的旧缺祖先场景：U6 已校验的 ownOnly 自有事实可读，其他非法/不可读详情继续报错，沿链结论和执行资格仍受限。
- 四条指标对照改为宽幅表格，固定名称列，身份标题可辨；自有消耗、沿链累计及相对共同祖先增量分开，缓存未知/零/部分记录明确区分。
- 模型实验继续要求直接 parent 相同、父链完整、已封存及配置/工具校验通过；只展示各臂事实和相对父 run 的累计增量，不计算臂间差值或胜出结论。普通阅读规则不能绕过这些限制。
- 文件仅提供分别打开左右运行 U2 文件页的入口，并保留合法检查点；读取失败可分别重试，迟到响应不串对象，不触发执行或改变 U3 草稿、U4 操作事实。

## Capabilities

### New Capabilities

无新增 capability 目录。

### Modified Capabilities

- `branch-tree`：分支定位与可访问交互、节点完整阅读、关系语义、宽幅多运行指标与完整性约束。
- `desktop-ui`：双运行工作区、修改/输出/步骤/消耗、比较读取与导航恢复、单侧文件入口和响应式阅读；解除既有条款中本阶段已实现入口的过渡限制。
- `model-experiments`：把现有比较前置条件接入共用工作区，明确读取校验、混选拒绝和禁止臂间结论；不扩大实验执行能力。

## Impact

主要影响 `BranchTree`、`ComparePanel`、`App`、概览/操作结果入口、store 导航与阅读状态，以及 shared 的关系、身份、概览与指标派生。新增只读比较读取适配与对应 shared/preload 校验，使两至四条记录的链路事实来自同次读取上下文，而非过期列表。模型实验仅复用或最小提取既有纯校验，不调用执行编排来验证历史结果。

继续使用 React、zustand、现有 SVG、Monaco 与 Lucide；不引入新图形库或其他依赖，不改变 JSONL、replay 执行和便携数据契约。U1/U2/U6 为硬前置，已归档 U3/U4/U5 的草稿、操作与导航行为必须回归。

## Non-goals

- 不实施 U8 录制/实验编辑工作区，不增加模型实验、隔离 prompt/A-B、并发、取消、执行权限或自动重跑。
- 不做跨运行文件 diff、文件写回、导出、合并/删除/重命名分支或 trace 修复。
- 不自动评判输出质量、生成总结、选最佳模型、计算模型实验臂间差值或排行榜。
- 不按同名模型、同轮号、相同 span ID 或相同文本猜测来源和共享前缀；不承诺无共同前缀步骤自动对齐。
- 不持久化比较阅读状态，不升级格式，不在文档起草阶段实施、归档、打包或发布。

## 保真度边界

比较及其重试均为本地只读，零模型/工具调用、零 trace/blob/source 写入；不请求或复活 sourceToken、副本授权及执行确认。已有 pure 工具的记录可核对，best-effort/副作用工具仅表示当时记录，不能由两次输出推断外部状态相同。隔离 result 保留整轮续跑边界，普通 result 保留既有 span 截断；prompt 是从头重跑，代理是单请求重发，模型实验是独立执行，均不冒充共享前缀或公平隔离实验。

## 验收口径

按 tasks 建立逐场景证据索引，覆盖 R8/R9、普通/隔离父子、多跳/兄弟/不同根/缺祖先、模型实验可比与拒绝、长文本与短 ID 碰撞、四列指标、快速换边与返回、文件合法定位和只读不变性。必须用受控 Electron 实机验证几何、滚动、键盘与真实点击落点；strict 文档校验不能替代功能验收。
