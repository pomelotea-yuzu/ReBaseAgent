# U8：录制与已有实验的工作区整合

## Why

U1–U7 已归档，创建、草稿、操作核对和比较已形成工作区流程，录制配置仍位于设置对话框，模型实验与代理 messages 编辑仍嵌在调用详情。用户需要在这些入口之间连续配置、预览、执行、查看结果和返回，且不能因页面迁移丢失输入或混淆代理监听、执行状态与实验结局。

本 change 对应 [U 拆分计划](../../../docs/engineering/plans/2026-09-21-ui-change-split-plan.md) U8 和 [UI 方案](../../../docs/engineering/plans/2026-09-19-ui-layout-discussion.md) §11/§15.4/§16。基线为 U7 归档提交 `d53b7d0`；现行 `desktop-ui` 70 requirements / 351 scenarios、`model-experiments` 13 / 43、`llm-proxy` 6 / 19。U7 的 62 条任务已完成；本轮仅起草 U8，尚未实施。

## What Changes

- 将录制接入移入独立全局工作区，设置仅提供跳转；分别展示保存的启用意图、真实监听、端口/upstream 和本会话凭据状态。监听成功后才提供真实本地接入地址复制，配置失败保留输入并重新读取真实状态。
- 增加会话内录制配置草稿和未应用提示，沿用现有配置写门禁和窗口关闭保护；凭据值始终不进入 renderer、草稿或日志。提供查看代理记录和显式刷新，不发送连接测试请求。
- 现有模型实验通过运行级菜单进入完整工作区，以父 run 和首次自有 llm.call 定位批次草稿，默认两臂，保留现有增删臂、标量参数、工具与来源门禁。
- 直接消费后端 dry-run 的生效参数、覆盖/新增、丢弃值和告警；计划绑定目标、草稿修订、运行配置变化和检查代次。修改、来源失效、配置变更或离开再恢复后重新预览与确认；迟到响应不得恢复旧计划。
- 真实实验执行复用 U4/U5 的身份、单槽、冻结、核对、结果读取和修订清理；按 main 登记的预期臂、真实 runIds 与 experimentId 展示完整批次，不把只包含成功臂的响应 `ids` 当作完整结果。
- 提供单臂打开、失败定位、只读重试、返回批次草稿及选择两至四条进入 U7 的入口；实验比较资格仍由 U7 判定，不产出臂间差值或自动排名。
- 将代理 messages 编辑迁入带明确来源和返回入口的工作区，保留完整 JSON 草稿、单请求重发与当前代理凭据门禁，接入已有确认/操作/结果流程。
- 为录制、实验和 messages 工作区补齐可视化状态、窄窗、200% 缩放、纯键盘及跨入口回归；不保留两份分别维护同一配置或草稿的编辑表单。

## Capabilities

### New Capabilities

无新增 capability 目录。

### Modified Capabilities

- `desktop-ui`：录制页面与配置草稿、设置分离、实验/messages 工作区、来源返回和可访问阅读；修改现有代理与设置的过渡表述。
- `model-experiments`：桌面计划新鲜度、成本确认、真实批次分组及结果入口；保持执行、参数、工具和比较语义。

## Impact

主要影响 `App`、`GlobalBar`、`SettingsDialog`、`RunWorkspace`、`DetailPanel` 中现有 ModelAbEditor/MessagesForkEditor、store 导航与草稿状态；复用 `debugging-drafts`、`draft-submission`、`operation-result-view`、比较导航及现有 Monaco。main/shared/preload 默认继续使用 `proxy:status`、`proxy:toggle`、`proxy:fork`、`runs:modelAbPlan` 和执行登记，无新增 IPC、JSONL 字段或包层执行能力。

新增非敏感录制配置草稿需接入既有 dirty 汇总、放弃与关闭协商，不把它伪装为主动执行或模型配置密钥。若实施发现确需跨进程契约扩展，先修订本 proposal/design 与对应 delta。继续使用既定技术栈，不引入新依赖。硬依赖 U5 + U7，复用 U1/U2/U3/U4/U6 的已归档契约。

## Non-goals

- 不新增官方 Agent/CLI/IDE 适配、自动接入向导、provider 能力探测、连通性测试或录制实时仪表。
- 不新增多臂编排能力、隔离 prompt/A-B、并发、队列、真实取消、跨 main 重启任务恢复或自动重发。
- 不新增凭据回读、草稿磁盘持久化、工具权限、源目录写入、跨运行文件 diff、trace/blob 修复或格式升级。
- 不自动评分、排名、选择最佳模型或计算实验臂间差值；不把臂数称为准确 API 请求数或臆造金额。
- 不重建 U4 操作登记、U5 结果事实或 U7 比较派生，不以本次文档校验补记历史未验证项，不在起草阶段实施、归档、打包或发布。

## 保真度边界

录制反映经过本地代理的单个模型请求，不重建外部 Agent 工具、文件历史或运行世界。messages 重发是真实单请求 upstream 调用，不续跑外部 Agent。模型实验沿用普通 prompt fork 从头执行，各臂拥有独立内存轨迹；pure 工具维持已有保证，best-effort/副作用工具仅在既有声明下顺序执行，前臂可能改变后臂外部状态，不能称公平隔离实验。监听停止仅停止本地接入服务，不承诺取消外部 Agent 或在途请求。

预览、状态读取、结果读取及比较为只读，零模型/工具调用、零 trace/blob/source 写入；配置应用仅经现有配置通道，真实执行仅经现有登记通道。草稿恢复、监听成功、hasKey 或历史比较均不产生执行许可。

## 验收口径

按 tasks 建立逐场景 evidence-index，分别验证录制启停/端口占用/状态回读失败、凭据与重发、参数整体替换/告警、计划失效与竞速、完整及部分失败批次、只读重试、U7 门禁和草稿返回。受控 Electron 验证真实点击、纯键盘、1440/1360/1024/800px 与 200% 缩放，不用静态标记替代几何或操作证据。外部服务失败、环境限制和历史欠账单列；规划材料齐全不等于功能交付。
