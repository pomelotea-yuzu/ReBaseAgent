# U3：编辑草稿与关闭保护

## Why

U1、U2 已分别于 2026-09-23、2026-09-24 归档，工作区导航和文件阅读恢复已经具备。编辑内容仍依赖组件存活：`DetailPanel.tsx` 的工具结果、prompt、代理 messages 和 A/B 臂使用局部状态，prompt 切换字段还会重新填入原值；`CreateRunDialog.tsx` 的任务、系统指令和模式在卸载后重置。用户查看其他调用、关闭编辑或去设置核对配置，会丢失尚未放弃的输入。

本 change 对应 [U 拆分计划](../../../docs/engineering/plans/2026-09-21-ui-change-split-plan.md) U3、[UI 方案 V0.2](../../../docs/engineering/plans/2026-09-19-ui-layout-discussion.md) §9.3/§9.5 的草稿部分、§18.1 和 §17.2 的键盘规则。[走查 R2、R3 草稿部分、R10/R11](../../../docs/reviews/2026-09-21-ui-usability-walkthrough.md) 提供问题来源，不作为本 change 的验收证据。本轮核对了当前源码，未重新执行 GUI 走查。

## What Changes

- 在 renderer 会话内保存按 run/span/field 区分的工具结果、system/user prompt、代理 messages 原始编辑文本；创建草稿和 A/B 批次配置使用各自的类型，共享保留、修订和明确放弃规则。
- 切步骤、页签、运行、收起编辑器和设置往返保留输入；展示草稿标记及可返回的草稿列表，原记录不可用时仍能复制或放弃输入。
- 编辑区域保留原值与新值核对；明确区分“收起”和“放弃修改”，放弃实际变更须确认。保留空串、空白、未完成 JSON 和尚未通过校验的臂参数，不以提交校验代替草稿保存。
- 草稿不携带执行授权、预检结论或模型凭据。恢复后重新预检和授权；源目录 token 仅存独立的受限会话引用，仍遵守 main 的 15 分钟和一次性消费规则。
- 提交绑定草稿键与修订号并冻结对应草稿，响应不依赖编辑器挂载。本阶段所有执行响应均保留草稿，正常完成后的按修订自动清理由 U5 接入。
- main 拦截标题栏关闭、Alt+F4 和应用内 app.quit，向 renderer 核对当前 dirty 状态；草稿存在或状态无法确认时提供原生退出确认。关闭核对有超时、请求关联和防重入；超时只表示本次未能确认状态，不判定 renderer 已失联。锁前保留已接收输入，取消退出后恢复编辑。
- 修复仍保留的创建、设置和新增确认模态框的焦点循环、背景隔离、最上层 Esc 处理及关闭后焦点恢复。

## Capabilities

### New Capabilities

无新增 capability 目录。

### Modified Capabilities

- `desktop-ui`：以 ADDED requirements 扩展会话草稿、编辑与放弃、创建/A-B 草稿、授权隔离、提交修订、退出核对及模态焦点行为；既有阅读状态、执行通道和门禁不变。

## Impact

主要涉及 renderer 的 `store.ts`、`DetailPanel.tsx`、`CreateRunDialog.tsx`、`SettingsDialog.tsx`、`App.tsx`、`SpanTree.tsx`、草稿纯逻辑与模态基础组件；main 的窗口生命周期、关闭协商模块，shared/preload 的受限状态报告和查询接口。复用 zustand、现有 Monaco 懒加载、Lucide 和 Electron 原生对话框，不增加依赖。

硬依赖 U1；当前以 U1/U2 均已合入的主 spec 为基线。草稿与 U1/U2 阅读状态分开保存，避免阅读缓存清理或失效引用回退误删编辑内容。新增 IPC 仅传 dirty 元数据及关联标识，不传草稿正文或凭据，不扩展模型执行请求体、trace schema、replay 或文件读取契约。

## Non-goals

- 不持久化草稿，不承诺 renderer 重载、崩溃或应用重启后恢复，不新增自动保存到磁盘、导出或历史版本。
- 不保证 Windows 注销、关机、系统重启或强制结束进程时出现退出确认，不阻止系统结束会话。
- 不实现 U4 操作登记、执行槽、去重与未知状态核对；不新增真正取消或自动重发。
- 不实现 U5 创建工作区、跨页执行反馈、失败结果定位、设置流程重做或正常完成后的自动清理；当前创建过程仍遵守已有 busy 关闭限制。
- 不实现 U8 实验/录制工作区，不把模型连接、代理配置及密钥输入放入调试草稿仓库。
- 不扩展隔离 prompt/A-B、源目录权限、文件写入或 replay 保真度，不打包、发布、提交或归档。

## 保真度边界

输入、恢复、核对、复制、收起与放弃草稿均不产生模型/工具调用，不写 trace、附件或源目录。最终明确提交仍走既有执行路径：普通 replay 的 pure 工具遵守原契约，外部状态和副作用为 best-effort；隔离 result fork 只在重新预检并授权的副本内续跑。编辑工具结果不代表修改文件，退出不保证上游请求、费用或外部副作用撤销。

当前仅编写 change，实施任务全部待办；文档校验不代表功能或实机验收完成。
