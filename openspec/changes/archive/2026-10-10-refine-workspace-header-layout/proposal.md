# 收紧编辑与差异工作区页头布局

## Why

归档的工作区阅读与编辑优化已经解决了说明分层、编辑器高度和折叠入口问题，但真实窗口复查发现，重跑草稿、工具编辑、文件 diff 和输出 diff 的页头仍把标题、状态、操作和长说明纵向堆在左侧，挤占输入/差异正文，上方右侧留下大块空白。与此同时，原值面板收起时存在一个 React 节点复用问题，可能把原值覆盖到草稿编辑器中。

## What Changes

- 为编辑与差异工作区提供共享的两行页头：左侧放标题、当前对象和必要状态摘要，右侧放操作与可展开的详细说明。
- 将重跑、专注、实验、来源和显示控制接入页签右侧操作区；移除同一事实的重复页头说明。
- 让原值/草稿标签和编辑器上沿对齐，窄容器自动改为上下布局；文件与输出 diff 的正文使用释放出的剩余高度。
- 为原值、草稿和调整手柄设置稳定 React key，保证折叠/恢复、页面往返和非法 JSON 输入不会覆盖草稿。
- 保留来源身份、异常摘要、只读身份、确认门禁、修订绑定和既有执行语义。

## Capabilities

### Modified Capabilities

- `desktop-ui`：编辑和差异工作区页头布局、信息分层、正文可用空间及草稿恢复契约。

## Impact

影响 renderer 的工作区页头、重跑/工具/文件/比较视图、确认块和相关布局样式；复用现有 React、Tailwind、Monaco 与 zustand，不新增依赖、IPC 写通道、trace 字段或执行权限。

## Non-goals

- 不修改 R2.1 `export-run-results` change 或导出行为。
- 不改变模型、工具、代理、文件快照、trace、权限、确认和修订 CAS 语义。
- 不新增跨运行文件 diff、比较能力、专注模式或草稿存储机制。
- 不通过缩小字号、隐藏异常、删除来源身份或取消只读约束来获得空间。
- 不处理代理可靠性、真实执行恢复或打包发布。

## 保真度与执行边界

本 change 只改变现有事实和草稿的呈现、折叠、布局与恢复方式。折叠、页面往返和 diff 阅读不调用模型或工具，不修改源目录、父本、兄弟 trace 或附件；现有重跑、隔离续跑和 messages 单请求的消息复用及外部副作用边界保持不变。

## 验收口径

在真实 1210×713、800 和 640 CSS px 窗口检查标题/对象/摘要与操作/说明的左右分区、正文高度、窄窗上下布局、无水平溢出和只读身份。通过真实键入中文、日文、多行及非法 JSON，折叠/恢复原值、展开说明、录制页往返后逐字比较草稿和修订；不得出现 Monaco 失败占位或错误目标。
