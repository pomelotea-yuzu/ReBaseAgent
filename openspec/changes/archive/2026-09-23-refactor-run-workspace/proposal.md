# U1：运行工作区与概览

## Why

A3-A/B/C 已归档，普通和隔离运行均能执行、查看轨迹和文件，但固定三栏使正文在常见窗口宽度下不可读；打开运行仍停在“尚未选择 span”，用户必须自行寻找结果。运行列表缺少搜索，同名任务难以区分，错误终止还沿用正常完成的绿色状态。

本 change 是 U 可用性阶段的第一个交付单元，对应 [U 拆分计划](../../../docs/plans/2026-09-21-ui-change-split-plan.md) 的 U1，采用 [UI 方案 V0.2](../../../docs/plans/2026-09-19-ui-layout-discussion.md) §3/§4/§7/§9.1–9.2/§9.4 及相关 §17/§18 规则。以下是改造前的实机证据，不是本 change 的验收结果：

| 来源 | 已复现问题 | 证据 |
|---|---|---|
| R1 | 1024px 文件页仍常驻运行和步骤列，正文几乎没有宽度 | [1024px 文件页](../../../docs/reviews/2026-09-21-ui-walkthrough-assets/32-file-width-1024.png) |
| R6 | 打开运行没有输出或失败概览 | [打开隔离运行](../../../docs/reviews/2026-09-21-ui-walkthrough-assets/03-isolated-open.png)、[普通成功运行](../../../docs/reviews/2026-09-21-ui-walkthrough-assets/08-create-completed.png) |
| R9 | 记录查找困难，运行选择与分支视图返回关系不清晰 | [分支树](../../../docs/reviews/2026-09-21-ui-walkthrough-assets/26-tree.png)、[节点选择](../../../docs/reviews/2026-09-21-ui-walkthrough-assets/29-node-click.png) |
| R3 状态色 | 出错终止仍使用绿色状态 | [失败子运行](../../../docs/reviews/2026-09-21-ui-walkthrough-assets/20-fork-error-result.png) |

完整复现条件见[实际走查报告](../../../docs/reviews/2026-09-21-ui-usability-walkthrough.md)。R1 的文件内部宽度、R9 的树节点裁切和聚焦分别由 U2、U7 收口；U1 不宣称解决整组问题。

## What Changes

- 将固定三栏重组为全局栏、可折叠且可调整宽度的运行导航和主工作区。单运行包含概览、步骤、按能力出现的文件页签；步骤目录只出现在步骤页。
- 运行导航支持完整任务/ID 搜索、来源筛选、显式刷新、稳定且无碰撞的短 ID、完整模型名访问和清晰状态；摘要全部复用当前校验后的列表数据。
- 首次打开运行进入概览，按真实自有终止事件展示输出、错误、限制或中断，提供真实失败调用跳转；默认展示本次新增执行的指标，区分缓存缺失与零命中。
- 保留完整原始请求/响应、工具数据、错误解释、上下文预算地图及 Monaco 编辑能力，调整其阅读层级和正文空间。
- 按 run ID 保存会话内页签、选中 span、展开项及概览/步骤阅读位置；明确目标跳转优先于恢复，过期对象回退，迟到详情不得覆盖当前运行。
- 文件页提升为完整主工作区，直接承载已有 WorkspaceFileView；保留现有分支树、最多四条指标对照及所有创建/编辑/执行入口，统一列表、概览和树节点的状态语义色。
- 补布局、键盘、错误及只读回归场景，覆盖普通、隔离、历史、代理、prompt 和模型实验记录。

## Capabilities

### New Capabilities

无新增 capability 目录；在 `desktop-ui` 内新增运行工作区、概览和会话阅读恢复 requirements。

### Modified Capabilities

- `desktop-ui`：修改运行列表、来源过滤、轨迹树、原始调用详情、分支树/轨迹视图切换、缓存展示 requirements；完整保留其既有场景。新增工作区、概览、阅读恢复与响应式交互义务。
- `branch-tree`：补充“分支树以节点-边图呈现运行与分叉”的最小 delta，明确底层 `completed/crashed` 两态与按终止原因细分的节点文字/颜色，完整保留原有场景。构图、布局、边标注、高亮和比较规则不变；文件读取、执行协议和持久格式也不变。

## Impact

主要影响 `apps/desktop/src/renderer/src/{App.tsx,store.ts,index.css}`、RunList、SpanTree、DetailPanel 阅读部分及新增概览/工作区组件；共享纯派生放入 `shared/derive.ts` 或同目录内有明确职责的文件。BranchTree 接入共用状态文字/颜色并适配返回导航，WorkspaceFileView 仅调整承载位置。

现有 `RunSummary` 和 `RunDetail` 已提供 task/model/reason、events/chain/leafSpanIds，本次不扩展 IPC，不增加数据库或汇总缓存。新增 `lucide-react` 作为图标依赖，用于复制、刷新、折叠和设置等控件，理由是当前没有图标库，统一图标和可访问名称可避免各组件重复手绘；不引入 UI 框架。依赖安装和 lockfile 更新属于实施任务。

前置仅为已归档 A3 基线，不依赖 U2–U8。文档完成后仍须实施和桌面验收；本轮编写 change 不等于 U1 已交付。

执行回归复用已有 `apps/desktop/scripts/mock-llm-server.cjs`：已核实具备本地监听、FIFO 剧本、SSE 文本/工具调用及请求日志。该脚本当前统一返回 SSE，未提供非流式 JSON、HTTP 失败或延迟控制；不据此声称普通、代理和实验全部路径已有覆盖。任务 6.0 在 6.4–6.6 前核对请求模式、准备匹配剧本并按需补齐测试服务能力，不阻塞第 1–5 组。

## 过渡行为

- 新建入口在全局栏新增，列表标题区原入口继续保留并打开同一个现有 CreateRunDialog，满足现行创建 requirement；创建工作区由 U5 替换。
- 录制接入定位现有 SettingsDialog 的代理区域；设置、prompt/messages 编辑、模型 A/B 和普通/隔离 result 重跑保持现有入口与门禁。
- 旧执行成功后按既有逻辑选择结果运行；新选择在 U1 中有概览可读，但跨页执行状态、失败草稿收尾和不抢焦点由 U4/U5 完成。
- 旧分支树仍为宽幅视图，选中节点后通过“返回运行”进入相同 run 的工作区；保留四条指标对照。节点聚焦、尺寸、双运行输出比较归 U7，不显示未实现的对比按钮。
- U1 只恢复“文件”页签，检查点、文件、diff 模式及文件滚动仍沿用现有行为，U2 再完善。缺祖先导致详情失败时保留错误和重试，不伪造 U6 的部分读取。

## Non-goals

- 不实现 operationId、执行槽、状态核对、跨页操作通知、真正取消、实时执行订阅或跨进程恢复。
- 不实现草稿仓库、离开/退出保护或执行后自动清理的新语义，不把阅读状态当作草稿。
- 不重写文件内部目录/diff、自选检查点策略，不新增文件写入、导出、跨运行文件比较或附件修复。
- 不实现缺父链降级、分支树重新布局/聚焦、双运行输出比较、新建/录制/实验工作区。
- 不增加状态/模式筛选、关系范围筛选、项目分组、标签或后台详情补扫；这些 V0.2 扩展不属于本次任务/ID 搜索与来源筛选。
- 不修改 trace-format、workspace-isolation、replay、prompt-replay 或模型实验比较契约，不开放隔离 prompt/A-B、Shell 或真实测试能力。
- 不提交、归档、打包发行，不把改造前截图或文档校验当作新界面通过。

## 保真度边界

概览和步骤只读取已校验的记录，不额外请求模型生成总结，不因阅读调用工具或写入 trace/附件。普通 result replay 沿用 world-free 边界，pure 工具在原契约内可复现，外部状态和副作用仍为 best-effort；隔离模式仅在既有显式授权下操作分支副本。修改 tool_result 只改变模型观察，不重新执行所选工具、不撤销旧写入；文件事实仍由 C 的初始/自有完成步骤清单提供。正常结束、模型输出、文件变化和测试通过分别呈现，不新增质量保证。
