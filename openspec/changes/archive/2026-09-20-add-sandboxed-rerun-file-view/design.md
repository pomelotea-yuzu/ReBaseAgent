## Context

A 的 JSONL 保存完整检查点并提供按引用读取附件的包接口；B 已交付 v2 详情 IPC、隔离执行入口和来源定位。本段只增加文件结果查看。

## Goals / Non-Goals

提供初始/自有完成步骤的文件列表、文本差异与可诊断的附件状态，重启或迁移后保持只读可查。不提供编辑/回写/合并，不新增执行或改变 A/B 的契约。

## Dependencies and Boundaries

按 A → B → C 交付，本段实施前 A、B 已归档。trace-format/workspace-isolation/profile/配额和当前请求授权均由 A 收口；C 复用 B 详情 IPC 校验。发现契约缺口先修订相关计划和 spec，已归档契约经明确的新 change 处理。A 后续不新增 desktop 改动，C 负责自己的 main/preload/renderer 读取集成，不把显示义务退回 A。公共完整检查和本段证据索引独立完成。

## Decisions

### 1. 只读 IPC 与引用定位

| 通道 | 输入 | 返回 |
|---|---|---|
| workspaces:inspect | {runId,stepSpanId?} | 清单、路径/大小、相对初始新增/修改、附件可用性与来源 |
| workspaces:readFile | {runId,stepSpanId?,path} | 完整 UTF-8 文本，或二进制/不存在/缺失/损坏状态 |

所有请求沿用统一 zod 与 IPC 信封，renderer 零 fs。main 注入现有便携 dataDir；runId 必须校验为 tracesDir 内的合法运行标识后由仓库定位，不能通过分隔符/绝对路径穿越目录，step 缺省取该 run 初始清单，指定 step 仅接受该 run 自有完成步骤。基于原始 run/leafSpanIds 确认所有权，不从合并轨迹选祖先快照冒充自有状态。逻辑 path 必须属于该清单；拒绝 renderer 提供的物理 blob 路径、存储根及清单外路径。

调用 A 的只读定位/读取接口验证清单、附件 hash/bytes。路径不存在、缺 blob、哈希/长度损坏、非 UTF-8 分开返回；没有文本的一侧在 diff 中明确标作不存在，不能把缺失或损坏当空文本。所有检查只读、不补写快照、不读 source 兜底、不调用 LLM/工具。

### 2. 差异与所属 run

文件列表从本 run 初始和所选完成步骤的合法清单派生：按逻辑路径与 hash 判定新增/修改，不使用 mtime、不持久化汇总缓存。当前固定工具组没有删除文件操作，不凭空增加删除能力。文件表显示大小/路径/状态，附件可用性单独呈现。

选择模型保留 {ownerRunId,stepSpanId,localIteration}，n 取所属原始 step；选择器文案“本 run 第 N 轮结束”，分支起点来源另外标父 run 和 step。根 A 3 轮、子 B 本地第 1 轮再分叉 C 时，B 的选择器不能写第 4 轮，C 起点来源不能写成 C 自有第 1 轮。初始快照不伪造为完成步骤。

### 3. 文件视图与状态

详情新增文件 tab，与轨迹并列；可选初始或任一自有完成步骤。紧凑文件表到内容的切换保留 run/步骤/路径状态，返回轨迹保留定位。文本复用现有 Monaco 离线装配，新增懒加载 DiffEditor 并排展示初始与所选完整内容，长内容滚动/折叠不截断。窄窗口可在列表和内容间切换，不遮挡导航。

二进制只显示原字节大小/哈希，不有损解码。未录制检查点、文件不存在、缺失和损坏分别表达，不只靠颜色，不触发文本比较或空文件占位。已失败封存 run 的已落盘快照仍可看，不伪造未落盘步骤。没有回写/应用到源目录按钮。

### 4. 重启、迁移与验证

重启或整体移动 JSONL 与引用 blob 后，从当前 dataDir 和 trace 相对引用重新读取，无需原 source。仅迁移 JSONL 时轨迹仍可读、附件明确缺失。查看不创造新的运行或文件，也不修补清单。

CDP 使用 A 合法 fixture 或 B 创建的运行：打开初始/步骤文件、比较差异、重启与移动数据目录后复查，覆盖 LLM 失败后已记录快照。对源目录、父/兄弟及已有附件逐字节/hash 复核；截图仅验证窗口布局，不能替代文件不变性测试。未知/越权 IPC 单独测，全部不读取目标宿主文件。

## Risks / Trade-offs

- 合并轨迹中的祖先 span 容易误选：main 与派生层校验本 run 所有权，来源单独呈现。
- 缺附件容易被误当空文件：明确状态并禁用无效文本比较，完整轨迹继续可读。
- 大文本与窄窗口：懒加载 Monaco，保持完整内容并提供切换/滚动，不静默截断。
- 检查后附件可能变化：实际读取仍验证 hash/bytes，失败明确返回，不绕过到源目录。
- 文件查看没有执行授权：不从审计字段或浏览行为推导新执行权限。

## Migration Plan

B 归档后核对详情 IPC/来源模型和 A 包读取接口，新增 C 的只读通道，再接派生和文件 UI。验收文件 CDP、重启/迁移、二进制/缺失/损坏、越权及窗口截图，完成全仓检查和本段证据索引后归档。不改写历史记录。
