# R2.1 实施任务

> 状态：2026-10-05 修订，所有实施任务待实施；evidence-index 已建立规划骨架，未登记功能通过。每项任务控制在 2 小时以内，超时先拆分；括号精确引用 delta 场景名，保留旧场景也需本轮回归证据。

## 1. 包层导出定位与契约

- [ ] 1.1 复核 evidence-index 骨架与 delta 全场景映射；固定包层请求/结果、错误码、当前 trace/附件校验边界，不在包层新增父链检查或接受任意快照/物理附件字段。（对应：祖先、清单外路径和非法来源被拒绝；父文件缺失不否定包层自有快照）
- [ ] 1.2 新增目标目录校验：存在、普通、为空，拒绝目标链接及与 dataDir 相同/互为祖先后代；按实际宿主规则预检物化路径，不静默改名。（对应：非空目标和取消选择不覆盖既有内容；目标排除数据目录及竞争写入）
- [ ] 1.3 固定读取本次 run 初始/自有 step 的快照引用，禁止逐文件重新定位拼接不同清单；覆盖根、分支本地 step、失败/未封存 run 已落盘 step 和缺省 step。（对应：导出根 run 的初始检查点；导出本 run 自有完成步骤；父文件缺失不否定包层自有快照）
- [ ] 1.4 实现逐文件附件读取、长度/哈希复核和来源失败映射；任一附件缺失、损坏或真实 I/O 错误都终止整次导出，不回读 source 或祖先。（对应：附件缺失或损坏不生成伪完整导出）

## 2. 文件物化与清理

- [ ] 2.1 实现固定 files/ 文件树布局、排他文件创建及目标字节复核；覆盖同名元信息路径、零字节/二进制，不创建 symlink 或保留硬链接身份。（对应：二进制字节导出但不进入文本补丁；项目同名文件不覆盖导出元信息）
- [ ] 2.2 实现产物登记、清单最后完成和失败逆序清理，仅删除仍属于本次请求的文件及空目录；非递归删除、同目标竞争不碰其他请求产物。（对应：写入中失败只清理本次产物；目标排除数据目录及竞争写入）
- [ ] 2.3 补充清理不完整诊断/残留相对路径及中断边界；完整关闭清单和目标复核才可成功，中断后不自动回滚或补写。（对应：写入中失败只清理本次产物；中断残留不被当作成功结果）

## 3. 清单与文本补丁

- [ ] 3.1 定义 format_version:1 清单 schema，固定 files_root/status 和 patch 三状态、覆盖/排除清单；注入时钟，保证除 created_at 外字段及排序确定；不写源路径、凭据或 messages。（对应：清单时间与不变量可独立核验；空快照与初始无变化可以导出）
- [ ] 3.2 实现补丁资格：可验证文本修改和清单证实的新增；binary/deletion 排除，基线附件不可用撤销整份补丁但不封禁完整选定文件导出。（对应：文本修改及新增有可证明的补丁；二进制和删除变化逐路径说明；初始附件不可用仅撤销补丁）
- [ ] 3.3a 实现确定性 unified diff：三行上下文、a/b 文件头、新增 /dev/null、路径引用及末尾无换行；内容保留 LF/CRLF 和顺序，不新增依赖。（对应：文本修改及新增有可证明的补丁）
- [ ] 3.3b 固定并测试补丁生成工作量上限，超限整份补丁不可用；实现补丁写入/哈希及无变化、全部排除状态。（对应：补丁超限保留完整文件导出；二进制和删除变化逐路径说明；空快照与初始无变化可以导出）
- [ ] 3.4 清单六类状态固定为“未保留（原状态未知）”，不猜测历史；测试 files[].status 恒 exported、初始/选定 ID、自有 step 来源均正确。（对应：清单时间与不变量可独立核验；导出根 run 的初始检查点）
