## MODIFIED Requirements

### Requirement: 文件阅读工具操作完整原文且保持只读

文件页 SHALL 提供路径及可读侧完整原文复制、查找、换行、上一/下一差异和 diff 模式控件，复用本地懒加载 Monaco。控件 SHALL 有可访问名称、状态、悬停说明和键盘焦点，按实际可读/可比较/编辑器就绪状态启用。文件页 SHALL 可在来源完整且当前检查点读取成功时提供导出选定检查点入口；该入口只复制已校验快照到用户选择的空目录，不提供编辑、替换、回写源目录、应用补丁或合并操作。

#### Scenario: 复制路径原文及元信息
- **WHEN** 用户在长路径、折叠或搜索后的文件上复制路径、某可读侧原文，或复制二进制/不可用附件元信息
- **THEN** 获得完整逻辑路径、该侧完整原文或真实大小/哈希，不复制截断显示内容，不把无文本侧复制为空文件；剪贴板失败就近提示

#### Scenario: 查找换行和差异定位使用当前文件
- **WHEN** 用户在可比较文本上查找、切换换行并导航上一/下一差异，再切换文件
- **THEN** 操作作用于当前文件和活动可读侧，差异导航使用已完成的真实 diff；切换后不沿用旧模型命令，换行不改原文，禁用替换和修改

#### Scenario: 不可比较或未就绪时工具诚实禁用
- **WHEN** 编辑器仍加载、内容未取得、两侧不可比较、没有差异或仅一侧可读
- **THEN** 按条件禁用对应复制/查找/差异工具并给出说明；单侧可读时该侧仍可复制查找，无差异时不假跳转

#### Scenario: 文件阅读键盘操作与离线加载
- **WHEN** 离线进入文件页并用键盘操作检查点、搜索筛选、目录切换、宽度调整、导出入口及工具栏
- **THEN** Monaco 从本地懒加载，控件可操作且有焦点态；返回列表聚焦原文件或有效列表项，关闭查找返回编辑器，无覆盖正文的工具控件

## ADDED Requirements

### Requirement: 文件工作区可以导出已核实的选定检查点

文件页 SHALL 提供“导出选定检查点”动作，目标为当前 run 的初始或自有完成步骤。确认 SHALL 显示检查点、空目录要求、files/ 文件树布局和未保留状态，取消 SHALL 零写入。renderer 请求 SHALL 只包含 runId 和可选 stepSpanId；额外 dataDir/source/blob/targetDir 等物理路径键 SHALL 拒绝。main SHALL 通过原生对话框取得目标，返回后在写入前独立重验完整父链，ownOnly 和其他来源错误分别给出导出语境的稳定诊断，不将 renderer completeness 当作依据；包层负责快照/附件/目标校验，不复制父链逻辑。

导出资格 SHALL 与文本编辑器、选中文件、diff 和主动执行槽分离。已核实检查点与完整来源可启用入口，已知选定附件失败须说明并禁用/拒绝；提交时仍复验全部附件。导出虽读取历史事实但会显式写目标目录，SHALL 单独防重复且不占用/释放主动执行槽、不登记 operation、不消费授权、不调用模型或工具。同 main 在飞保护 SHALL 不因 renderer 重载消失；返回/重载 SHALL NOT 自动重发写入。

成功反馈 SHALL 显示实际目标目录、files/ 位置、导出文件数/文件字节数、清单、文本补丁状态/覆盖范围及未保留状态；补丁不可用 SHALL 不被描述为完整文件导出失败。失败/取消 SHALL 显示原因并保持当前 run、检查点、文件选择、阅读位置和草稿。响应及 loading 收尾 SHALL 绑定提交 run/step/请求代次，迟到反馈不覆盖新对象、不抢焦点；离开页面不取消 main 导出，返回可查看匹配的会话反馈，重载丢失回执时说明结果未知并指引检查目标，不自动重试。界面 SHALL 不把导出成功描述为测试通过、项目可运行、自动应用或合并成功。

#### Scenario: 从文件页导出成功
- **WHEN** 用户在完整来源的隔离 run 中选择初始或本 run 自有完成检查点，选择空目录并确认导出
- **THEN** 目标 files/ 得到与检查点一致的文件树，根部得到 rebaseagent-export.json 清单及适用的 changes.patch，界面显示实际布局、数量/字节/补丁覆盖状态，当前阅读位置不变

#### Scenario: 目标目录非空或取消选择
- **WHEN** 用户选择含既有文件的目录，或在目录选择/确认阶段取消
- **THEN** 不写入既有目录，不创建运行或附件，界面保留文件页和选择状态并给出可操作原因

#### Scenario: 来源不完整时禁用或拒绝导出
- **WHEN** 当前 run 为 ownOnly、选定附件缺失/损坏、普通无 workspace 或检查点仍在加载，或目录对话框期间父链由完整变为不可读/不完整
- **THEN** 导出入口禁用或 main 写入前重验返回来源/附件诊断，ownOnly 自有文件仍可按原规则阅读；不伪造结果、不回读源目录、不消费授权

#### Scenario: 导出失败后恢复阅读
- **WHEN** 导出写入期间发生磁盘错误或清单生成失败
- **THEN** 显示失败及清理诊断，目标中不保留本次半成品（清理失败须明确提示），当前 run/文件选择/草稿和操作状态不被改写

#### Scenario: 导出成功不改变主动执行边界
- **WHEN** 用户在主动操作运行中、配置锁定或存在未提交草稿时浏览文件并导出已核实检查点
- **THEN** 导出按只读入口执行，不占用或释放主动槽，不改草稿/授权/配置，不触发模型、工具或导航抢焦点

#### Scenario: 无文本差异和二进制不封禁检查点导出
- **WHEN** 检查点与来源已核实，但当前是初始、空快照、无变化、二进制文件、无选中文件或 Monaco 尚未加载
- **THEN** 导出入口仍可用且提交仍校验全部附件，复制/查找/diff 工具各按原资格启用，文本不可比较不被当作文件导出失败

#### Scenario: 补丁不可用不隐去成功文件导出
- **WHEN** 文件树完整导出但补丁因基线附件不可用、二进制/删除变化或工作量超限而不可用或未覆盖全部变化
- **THEN** 分别显示文件已导出、补丁具体状态与逐路径原因，不显示虚构补丁文件，不把未覆盖变化说成已包含

#### Scenario: 导出请求迟到或重载不重发写入
- **WHEN** 导出在飞时切运行/检查点、离开文件页、重复点击或重载 renderer
- **THEN** main 防止重复在飞导出，旧响应/finally 不覆盖新页面或抢焦点；返回读取匹配会话反馈，重载丢失回执显示结果未知且不自动重发写入
