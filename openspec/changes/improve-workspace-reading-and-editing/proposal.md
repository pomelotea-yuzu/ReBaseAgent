# 优化工作区阅读与编辑空间

## Why

用户在 agent 测试与视频制作中观察到：页面内容的折叠入口不明显，说明文字占用过多空间，难以连续编辑或阅读 diff。2026-10-06 实机截图（真实 1210×713 CSS px）确认：列表收起入口是约 16×16px 浅色箭头；文件页重复显示隔离说明，多层说明与工具栏使一条实际路径的 diff 从 y≈509 开始；messages 原值/草稿各固定约 200px 高，核对与提交跨出首屏。收起列表只加宽，不能解决高度问题。

详见 `docs/reviews/2026-10-06-ui-density-review.md`，几何读数见 `docs/reviews/2026-10-06-ui-density-geometry-baseline.json`。本次优化要增加可阅读、可输入空间，同时保留来源身份、重要异常与本次执行边界，不通过缩小文字或隐藏真实状态实现“清爽”。

## What Changes

- 统一列表、步骤、文件目录、长文本、一般说明与修改证据的展开/收起控制，使用可见文字、方向/状态、合理命中区及键盘焦点，收起后保留恢复入口。
- 同屏去重隔离/来源说明，把一般解释与 profile/world/snapshot/hash 等技术细节分层展开；来源与工程说明共用可访问详情机制，重要异常和当前两侧/来源身份常驻。
- 编辑和 diff 使用实际容器可用空间；原值/草稿按每侧最小宽度适配并排或上下，提供专注模式及可调整区域，保持字号。专注由现有布局机制按目标持有临时模式，不复制草稿/阅读状态或改写手动偏好。
- 本次核对和提交在相邻操作区，简明费用/副作用摘要保留，详细边界可展开；绑定修订及许可的行为不变。
- 改善放弃修改模态的遮罩与居中视觉，保留原生 top layer、焦点限制、Esc 与修订 CAS。
- 用户文案用“未做修改”“尚未提交”“仅重发本次请求”等结果描述，技术原因可展开；统一“时间旅行（隔离续跑）”的入口说明，不扩大能力。

## Capabilities

### New Capabilities

无新 capability 目录。

### Modified Capabilities

- `desktop-ui`：增加一致的折叠控制、说明分层、编辑空间、专注模式、相邻确认及清晰模态/文案要求。

## Impact

影响 renderer 的 App/GlobalBar/RunList/SpanTree、RunWorkspace/DetailNotices/WorkspaceFileView、MessagesForkEditor/DetailPanel/ModelAbEditor、CompareWorkspaceView、LongText/ModalDialog 及布局/会话阅读状态。复用现有 React、Tailwind、Monaco 和草稿机制，不引入新依赖；不新增 IPC 写通道，不变更 trace 和导出数据。正在起草的 `export-run-results` 若后续增加文件页动作，应放入紧凑工具栏，不能重新挤占内容区；本 change 不交付导出。

## Non-goals

- 不修代理列表 freshness、凭据同步、上游错误录制或启动恢复，这些归 `fix-proxy-recording-reliability`。
- 不将编辑器零尺寸根因调查或就地恢复机制重复实现；本次布局必须回归前一 change 的恢复契约。
- 不新增比较视图页签、跨运行文件 diff、隔离 prompt/模型实验、最近目录、快照容量统计、目录预检接口或中断运行重新发起。
- 不把有来源问号的数据改成中文，不改变缓存 token 数字或以 UI 纠正未知 provider 数据。
- 不取消两段确认、来源门禁、当前凭据规则、工具副作用授权或安全退出保护。
- 不在起草阶段修改实现、归档、打包或发布。

## 保真度与执行边界

只改变现有事实与草稿的呈现和操作布局。折叠、专注、调整区域、查找、复制和往返不调用模型/工具，不改源目录、父本、兄弟 trace 或快照。普通 result 续跑复用既有前缀；prompt 从头执行；代理 messages 只重发单请求；隔离 result 从整轮轮末快照继续，编辑观察不撤销同轮写入。上述差异必须在本次提交前的摘要/详情可辨，不以“时间旅行”概称承诺外部环境恢复。

## 验收口径

真实窗口基线与宽窄/缩放矩阵检查文字控制可发现、收起后可恢复、无重复说明、正文不缩小。至少在 1210×713 的正常文件页/专注编辑下，主要内容从首屏中部之前开始，并获得不少于视口高度一半的可见区域；复杂异常不满足时须证实必要告警占用及专注/内部滚动退路。长原文/非法 JSON、精确草稿、目标、滚动/光标在专注/折叠/往返后保持；核对与提交相邻，旧授权仍失效。附实际输入和纯键盘证据，不能只凭截图比例声称可编辑。详见 tasks/evidence-index。
