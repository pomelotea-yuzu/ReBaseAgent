# 现有软件完整中英双语

状态：提案，尚未 apply。此次只建立 change，不改变实现与发行状态。

## Why

用户文档已有主要英文使用路径，软件仍以中文硬编码提示为主，非中文用户无法连续完成配置、调试和结果核对。[阶段决策](../../../docs/product/2026-10-09-promotion-i18n-decisions.md)明确要求完整覆盖现有软件，MCP、CLI、原生对话框均在本阶段内。

[2026-10-28 盘点](../../../docs/engineering/reports/2026-10-28-i18n-text-inventory.md)及本地 `.tmp/i18n-inventory.json`（北京时间 00:39:32 生成）显示：3,603 处、3,105 条去重中文文本；renderer 2,252 处，其中 lib/ 715 处；main/shared 共 226 处，包层 1,125 处。1,060 处含插值、274 处含量词；至少 1,138 条测试断言引用 UI 文案。现有测试使用 Node 和同步静态渲染，方案必须兼容。

报告标注基线 `f1c132a`；本次检查 HEAD `dd32fef`，两者间桌面及包层 src 无变更。数量是候选文本规模，不是最终键数或工时；生成资产、模型上下文和历史正文须逐项分类，不能见中文就替换。

## What Changes

- 新增纯 TypeScript 共享 i18n 包、同步内置的 `zh-CN / en-US` 资源、术语表、参数插值、复数和富文本消息。
- 桌面增加“跟随系统 / 简体中文 / English”。默认跟随系统，zh 及其区域变体取简体中文，其余或检测失败取英文；独立保存在当前数据根 `ui-preferences.json`，与模型密钥、运行配置和配置修订解耦。
- 按完整工作区迁移入口、核对、执行、错误和结果，覆盖全部现有页面、可访问名称、图表/编辑器外围提示与应用控制的原生对话框。
- 稳定错误 code 与受控消息标识/参数分离，展示端翻译产品解释；原始异常、模型输出、文件和日志保留原文。历史及新产生的持久化业务正文均不随 UI locale 改写。
- 即时切换保留草稿、焦点、阅读位置与在飞身份；未提交的费用、写入、副作用和验证准备/测试确认清零，要求重新核对。在飞操作继续按原身份核实，不重发。
- MCP、CLI 增加 `--locale zh-CN|en-US` 和 `REBASEAGENT_LOCALE`，进程启动确定语言。翻译十三工具说明、信任声明、受控错误与人类报告，保持稳定协议字段、原始事实和机器报告。
- 新增双语资源和候选文本归属门禁，按工作区迁移测试，完成两语言真实 Electron 布局与状态验收。

## Capabilities

### New Capabilities

- `software-i18n`：语言解析、同步翻译、结构化产品消息、原文和机器数据边界。

### Modified Capabilities

- `desktop-ui`：偏好、即时切换、确认失效、全工作区双语可用性。
- `mcp-service`：启动语言、十三工具元信息、有界本地化响应。
- `trace-as-test`：CLI 人类报告双语及稳定 JSON。
- `ci-gates`：资源完整性、分批迁移、覆盖门禁与实机证据。

## Impact

新增 `packages/i18n`；接入 desktop shared/main/preload/renderer、相关包层错误投影、MCP、trace-test 和其余已有包层 CLI。新增严格的 UI 偏好读写通道，不向主动操作请求加入 locale，不改原通道名、执行载荷和去重指纹。

拟新增 `i18next` 与 `react-i18next`：约三千条候选文案涉及复数、富文本和 React 订阅，复用成熟实现以避免自建消息解析器。纯包只依赖 i18next，React 适配限于桌面；不加语言检测插件、HTTP backend、ICU 解析器、DOM 测试框架或在线翻译服务。实施时固定版本、核对许可和同步初始化行为，提交 lockfile。

全部批次属于同一 change，不能以核心演示路径替代全软件覆盖。同步实际入口涉及的双语指南，不重做已完成的文档翻译。具体决策见 [design.md](design.md)，任务及场景映射见 [tasks.md](tasks.md)。

## Non-goals

- 自动翻译用户输入、模型响应、工具结果、历史 trace、文件、验证 stdout/stderr 或其他证据正文。
- 改写发给模型的 prompt、工具描述、工具结果或错误内容；明确纳入的 MCP 对外工具元信息除外。
- 新语言、繁体资源、翻译平台、云同步、自动机器翻译。
- 新平台、新业务功能、全局重设计、通用 Shell、授权流程重构、打包或发布。
- 全量翻译 docs/、注释、测试标题、内部诊断或生成 runner 脚本。

## 保真度边界

只改变产品展示。普通 result 续跑仍复用分叉前消息，之后真实调用模型/工具；prompt fork 仍从头执行，代理 messages 仍只重发一个模型请求。隔离续跑仍从编辑点所在整轮的轮末普通文件快照副本继续，不撤销同轮写入，不恢复网络、数据库或任意外部状态。切语言不改消息、快照、工具输入输出、config hash、计划指纹和操作身份，不执行、不导出。偏好写入仅限自己的偏好文件，不改业务记录。

## 验收口径

两语言覆盖全部现有工作区、MCP、CLI 和原生提示；动态错误、未知状态、费用/授权边界同义。缺键回退只用于运行期容错，不能豁免缺失英文。按场景记录单元/组合测试、CLI/MCP 子进程实测及真实 Electron 证据；全仓 `pnpm check:ci`、单独 desktop build、change strict 均通过后收口。本次不预记任何实现验收为已通过。
